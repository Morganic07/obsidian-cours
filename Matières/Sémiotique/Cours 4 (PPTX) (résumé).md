Résumé du Cours 4 de [[Sémiotique (matière)]] (séance 4 : « Le formatage, c'est du pouvoir », 28 diapositives). Précédent : [[Cours 3 (PPTX) (résumé)|Cours 3]].

**Objectifs.** Regarder l'écran comme un dispositif de pouvoir ; analyser son corpus sous l'angle des enjeux de pouvoir ; s'accorder sur les hypothèses (de recherche et de design) de l'étude de cas. Le diaporama met à jour les livrables : les notes 3 et 4 deviennent les notes 2 et 3 (barrées sur la diapositive), ce qui semble indiquer une réorganisation du barème.

**L'architexte.** Outil régissant les opérations et les formes du texte à l'écran ; écriture de l'écriture, qui contient une représentation de l'activité par ses concepteurs. Des « partenaires éditoriaux invisibles » qui standardisent et formatent (Word, Facebook, WordPress) ; liberté d'expression circonscrite. Exemple : le logiciel de présentation impose une structure, une hiérarchie, une temporalité linéaire. Voir [[Architexte]].

**L'âge du code.** Chaque geste repose sur du code qui formate nos actions. « Désenfouir » le code : le fil d'actualité est un classement algorithmique, les likes quantifient le social, les suggestions sont des inférences, les stories imposent une temporalité programmée. Le code intervient dans l'énonciation (données, formats, métadonnées, feuilles de style).

**La novlangue du digital.** Les mots ne sont jamais neutres : « smartphone » (l'objet devient intelligent), « cloud » (la technique devient immatérielle), « machine learning » (la machine apprend), « partager », « amis ». Ils programment la perception des technologies.

**Des assemblages préfabriqués.** Menu hamburger, barre de recherche, bouton like, fil, carte, profil : formes standardisées qui anticipent les comportements ; tension entre liberté d'expression et formatage industriel. Pour une application de nature : feed vertical, profil, métriques (observations, identifications, abonnés), likes et commentaires : le vivant est intégré dans une grammaire sociale standardisée.

**La logique du marché.** Choisir une application, c'est adhérer à un écosystème, afficher une appartenance. Exemples : messageries (modèle économique et rapport aux données différents) et outils de conception (Figma, Adobe, Canva, Sketch : culture professionnelle et dépendances). L'outil façonne la pratique autant qu'il la permet.

**Économie des données.** L'utilisateur, producteur de données et « travailleur involontaire » ; chaque texte numérique produit de la valeur. Pour une application de nature : identifier une plante, c'est analyser une image, enregistrer une localisation, nourrir une base mondiale ; cela produit cartographie de la biodiversité, standardisation taxonomique, datafication du vivant.

**Grille 3 : analyser les médias numériques.** (1) Le pouvoir des outils d'écriture sur le social (imaginaires et formes de communication convoqués) ; (2) se projeter dans l'agir du code (signes visibles du code, action transformante, représentation de l'utilisateur) ; (3) interroger les mots du numérique (performativité du langage) ; (4) déconstruire les assemblages préfabriqués (boîtes, formulaires, menus ; logique de fabrication industrielle) ; (5) comprendre la marchandisation (type de dispositif, rôle assigné à l'utilisateur, idéologie sous-jacente). Voir [[Analyse techno-sémiotique]].

**Planning.** Séances 5 et 6 : avancée de l'étude de cas, analyse en classe, exercices créatifs (1 et 2 puis 3 et 4).
