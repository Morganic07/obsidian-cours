## Liens avec les autres matières

- **[[Bilinear Algebra (index)]]** : les mêmes notions en anglais, à partir des matrices (voir ci-dessous les correspondances de vocabulaire).
- **[[Outil Maths (index)]]** : la [[Bijection]], la [[Composition de fonctions]] et la [[Fonction identité]] y sont vues pour les fonctions en général, avant d'être appliquées ici aux applications linéaires.

## Correspondances de vocabulaire

- Famille libre : linearly independent set
- Famille génératrice : spanning set
- Système compatible : consistent system
- vect$(\dots)$ : Span$\{\dots\}$
- Ker $f$ : Nul $A$
- Im $f$ : Col $A$
- rg : rank

Attention aux tailles : ce cours note une matrice $n \times p$, avec $n$ lignes, alors que Bilinear Algebra note $m \times n$.
