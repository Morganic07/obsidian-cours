## 1. Les bases

### Qu'est-ce que le C++ ?

Le C++ est un **langage compilé** (traduit en binaire avant exécution, pour la rapidité), créé au début des années 1980 comme une **extension du C**. Il ajoute au C la [[Programmation orientée objet|programmation orientée objet]] (classes, objets, héritage…) tout en restant proche de la machine : c'est un langage rapide et très utilisé.

Le langage a été conçu par Bjarne Stroustrup aux Bell Labs, d'abord sous le nom « C with Classes » (1979), puis renommé C++ en 1983 : le nom joue sur l'[[Opérateur d'incrémentation|opérateur d'incrémentation]] `++`, « le C, un cran plus loin ». Il est normalisé par l'ISO depuis 1998 (C++98, norme ISO/IEC 14882), avec des révisions régulières : C++11, qui a profondément modernisé le langage, puis C++14, C++17, C++20 et C++23. Presque tout programme C valide est aussi un programme C++ valide, mais pas tous (le C++ a des mots réservés en plus, comme `class` ou `new`, et des règles de typage plus strictes). [[Complément hors du cours|ⓘ]]

**L'héritage**, seulement nommé par le cours, consiste à définir une classe à partir d'une autre : la classe dérivée reçoit les attributs et méthodes de la classe de base et peut en ajouter ou en redéfinir. Par exemple `class Cercle : public Forme { … };` fait de tout `Cercle` une `Forme`. Voir [[Héritage (programmation)]]. [[Complément hors du cours|ⓘ]]

| Domaine | Exemples |
|---|---|
| Jeux vidéo | moteurs 3D, performances temps réel |
| Systèmes embarqués | automobile, aéronautique, robotique |
| Logiciels et OS | applications lourdes, systèmes d'exploitation |

```cpp
int x = 10;
int y = 20;
std::cout << x + y;   // affiche : 30
```

### Structure d'un programme

```cpp
#include <iostream>

int main() {
    std::cout << "Bonjour, C++ !" << std::endl;
    return 0;
}
```

| Élément | Rôle |
|---|---|
| `#include <iostream>` | importe les fonctionnalités d'entrée/sortie (comme `std::cout`) |
| `int main() { ... }` | point de départ obligatoire de tout programme C++ |
| `std::cout << ...;` | affiche du texte ou une valeur à l'écran |
| `return 0;` | indique que le programme s'est terminé sans erreur |

- `std::` est l'[[Espace de noms (namespace)|espace de noms]] (*namespace*) de la bibliothèque standard (*Standard Library*).
- On appelle la fonction d'affichage `cout`, suivie du texte `"Bonjour, C++ !"` entre les chevrons `<<`.
- `std::endl` ajoute le caractère de fin de ligne de la bibliothèque standard.
- La directive `using namespace std;`, placée après les `#include`, permet d'écrire `cout`, `endl` ou `string` sans le préfixe `std::` : c'est ce que suppose l'aide de l'exercice `Maze` plus bas, qui écrit `ifstream` et `cout` seuls. Elle est commode dans un petit programme, mais déconseillée dans un fichier d'en-tête, où elle importerait tous les noms de `std` chez quiconque l'inclut. [[Complément hors du cours|ⓘ]]
- `#include` est une directive du **préprocesseur** : avant la compilation proprement dite, le contenu du fichier nommé est recopié à cet endroit. Les chevrons `<iostream>` désignent un en-tête de la bibliothèque standard ; les guillemets `"point.h"` un fichier du projet. Voir [[Chaîne de compilation]]. [[Complément hors du cours|ⓘ]]

### Les types de base

| Type | Nature | Exemple |
|---|---|---|
| `int` | nombre entier | `int age = 25;` |
| `double` | nombre décimal | `double prix = 19.99;` |
| `char` | un seul caractère | `char lettre = 'A';` |
| `bool` | vrai / faux | `bool actif = true;` |
| `std::string` | chaîne de caractères | `std::string nom = "Léo";` |

Chaque variable doit être déclarée avec un type : il indique la nature de la donnée et l'espace mémoire qu'elle occupe. **Identique au C** (voir [[Type primitif]], [[Typage statique]]), à `bool` et `std::string` près.

`std::string` n'est pas un type de base comme les quatre autres : c'est une **classe** de la bibliothèque standard (il faut `#include <string>`), qui gère seule sa mémoire. On concatène avec `+` (`nom + " !"`), on compare avec `==`, on obtient la longueur avec `nom.size()` ; en C, une chaîne n'est qu'un [[Tableau (programmation)|tableau]] de `char` terminé par `'\0'`. `bool` vaut `true` ou `false` ; converti en nombre, `true` vaut 1 et `false` 0, et `std::cout` affiche `1` ou `0`. [[Complément hors du cours|ⓘ]]

Le mot-clé `auto` (depuis C++11) laisse le compilateur déduire le type de l'initialisation : `auto n = 25;` déclare un `int`. Le typage reste statique : le type est fixé à la compilation. [[Complément hors du cours|ⓘ]]

### Variables et opérateurs arithmétiques

```cpp
int age = 25;
double prix = 19.99;
char lettre = 'A';
bool actif = true;

int somme = age + 10;
int carre = age * age;
```

| Opérateur | Rôle |
|---|---|
| `+ - * /` | addition, soustraction, multiplication, division |
| `%` | reste de la division (modulo) |
| `=` | affectation d'une valeur |
| `== !=` | test d'égalité / de différence |
| `< > <= >=` | comparaisons |

Entre deux entiers, `/` donne le **quotient entier** : `7 / 2` vaut `3`, et `7 % 2` vaut `1` (voir [[Division euclidienne]]). Pour un résultat décimal, l'un des opérandes doit être un réel : `7.0 / 2` vaut `3.5`. `%` ne s'applique qu'aux entiers. Ne pas confondre `=` (affectation) et `==` (comparaison) : `if (x = 0)` affecte 0 à `x` et le test est toujours faux. [[Complément hors du cours|ⓘ]]

## 2. La sortie standard : `std::cout`

`std::cout` (« *console output* ») envoie du texte ou des valeurs vers la sortie standard, en général le terminal. L'opérateur `<<` permet d'y « insérer » plusieurs éléments à la suite (voir [[Flux d'entrée-sortie (C++)]]).

- `std::endl` insère un retour à la ligne (comme `"\n"`).
- `<<` peut s'enchaîner pour afficher plusieurs valeurs sur une seule ligne.
- `std::endl` et `"\n"` ne sont pas tout à fait équivalents : `std::endl` passe à la ligne **et vide le [[Tampon (buffer)|tampon]]** de sortie, ce qui force l'affichage immédiat mais ralentit les boucles qui affichent beaucoup ; `"\n"` passe seulement à la ligne. [[Complément hors du cours|ⓘ]]
- L'entrée standard (le clavier) se lit avec `std::cin` et l'opérateur `>>`, l'équivalent de `scanf` : `int age; std::cin >> age;`. `std::cerr` écrit sur la sortie d'erreur. [[Complément hors du cours|ⓘ]]

```cpp
int score = 42;
std::cout << "Score : "
          << score << std::endl;
std::cout << "Bravo !" << std::endl;

// Sortie :
// Score : 42
// Bravo !
```

## 3. La notion d'objet : classe et instance

Une **classe** est un modèle (un plan) qui décrit des données et des comportements. Un **objet** est une instance concrète de ce modèle (voir [[Classe et objet]]).

**Analogie** : `class Voiture` est le plan de fabrication (marque, couleur, rouler…) ; `voiture1` et `voiture2` sont deux voitures réelles, chacune avec ses propres valeurs.

```cpp
class Voiture {
public:
    std::string marque;
};

Voiture voiture1;
Voiture voiture2;

voiture1.marque = "Peugeot";
```

La définition d'une classe se termine par un point-virgule après l'accolade fermante (`};`) ; l'oublier provoque une [[Erreur de compilation|erreur de compilation]] souvent signalée sur la ligne suivante. Les données d'une classe s'appellent ses **attributs** (ou données membres), ses fonctions ses **méthodes** (ou fonctions membres). [[Complément hors du cours|ⓘ]]

En C++, `struct` et `class` sont presque synonymes : une `struct` peut elle aussi avoir des méthodes et des constructeurs. La seule différence est l'accès par défaut, **public** dans une `struct`, **privé** dans une `class`. L'usage réserve `struct` aux simples regroupements de données (voir [[Structure (struct)]]). [[Complément hors du cours|ⓘ]]

## 4. Données publiques et données privées

| Mot-clé | Accès |
|---|---|
| `public` | accessible depuis l'extérieur de la classe : n'importe quel code peut lire ou modifier cette donnée directement |
| `private` | accessible uniquement depuis l'intérieur de la classe : protège la donnée contre un accès ou une modification incontrôlés |

```cpp
class CompteBancaire {
public:
    std::string titulaire;
private:
    double solde;
};

CompteBancaire c;
c.titulaire = "Alice";   // OK — donnée publique
c.solde = 1000;          // Erreur : solde est privé !
```

Voir [[Encapsulation (programmation)]].

L'accès est contrôlé **à la compilation** : `c.solde = 1000;` est refusé par le compilateur, le programme n'est jamais produit. L'intérêt est de garantir les règles de l'objet (un solde ne bouge que par des méthodes prévues, qui peuvent vérifier les montants) et de pouvoir changer la représentation interne sans toucher au code qui utilise la classe. Un troisième mot-clé, `protected`, ouvre l'accès aux seules classes dérivées (voir [[Héritage (programmation)]]). [[Complément hors du cours|ⓘ]]

## 5. Les constructeurs

Voir [[Constructeur (programmation)]].

### Le constructeur par défaut

Un **constructeur** est une méthode spéciale appelée automatiquement à la création d'un objet : il **porte le nom de la classe** et **n'a pas de type de retour**. Le constructeur par défaut ne prend **aucun paramètre**.

```cpp
class Point {
private:
    int x, y;
public:
    // constructeur par défaut
    Point();
};

Point :: Point(){
    x = 0;
    y = 0;
}

int main() {
    Point p;    // p.x = 0, p.y = 0
    return 0;
}
```

`Point()` est appelé automatiquement à la création de `p` : les coordonnées `x` et `y` sont initialisées à 0.

Pour créer un objet avec le constructeur par défaut, on écrit `Point p;` **sans parenthèses**. `Point p();` ne crée pas d'objet : le compilateur y lit la déclaration d'une fonction `p` sans paramètre qui renvoie un `Point`. `Point p{};` est en revanche correct. [[Complément hors du cours|ⓘ]]

**Avec le cercle** (même schéma) :

```cpp
class Cercle {
private:
    float x, y;
    float rayon;
public:
    // constructeur par défaut
    Cercle();
};

Cercle :: Cercle(){
    x = 0;
    y = 0;
    rayon = 0;
}

int main() {
    Cercle c;            // c.x = 0, c.y = 0, c.rayon = 0
    return 0;
}
```

Le C++ distingue majuscules et minuscules : l'attribut s'appelle `rayon`, et `Rayon = 0;` ne compilerait pas. [[Erreurs du cours#^e-4-c|✎]]

### Pourquoi un constructeur par défaut ?

| Sans constructeur | Avec constructeur par défaut |
|---|---|
| `x` et `y` ne sont pas initialisés : ils contiennent une valeur indéterminée (n'importe quoi), voir [[Variable non initialisée]] | chaque `Point` est créé dans un état connu et prévisible : ici, l'origine (0, 0) |

```cpp
// Écriture équivalente : liste d'initialisation
Point() : x(0), y(0) {}

// Utilisation
Point origine;
std::cout << origine.x;   // affiche : 0
std::cout << origine.y;   // affiche : 0
```

La liste d'initialisation (après `:`) **initialise** les attributs dès leur création, alors que `x = 0;` dans le corps leur **affecte** une valeur après coup. Pour des `int`, le résultat est le même ; mais un attribut `const` ou une [[Référence (C++)|référence]] ne peut être qu'initialisé, et donc seulement dans la liste. Les attributs y sont initialisés dans l'ordre de leur déclaration dans la classe, pas dans l'ordre de la liste. [[Complément hors du cours|ⓘ]]

### Le constructeur par paramètres

Il reçoit des valeurs au moment de la création de l'objet et s'en sert pour initialiser directement ses attributs.

```cpp
class Point {
private:
    int x, y;
public:
    Point(int a, int b) {
        x = a;
        y = b;
    }
};

Point p1(3, 4);     // x = 3, y = 4
Point p2{5, 6};     // x = 5, y = 6
```

- **Définition** `Point(int a, int b)` : les paramètres `a` et `b` reçoivent les valeurs transmises, puis sont recopiés dans `x` et `y`.
- **Appel** `Point p1(3, 4);` : les valeurs 3 et 4 sont transmises au constructeur ; `p1` est créé avec `x = 3` et `y = 4`.
- Les accolades `Point p2{5, 6};` sont l'**initialisation uniforme** introduite par C++11 : elle appelle le même constructeur, mais refuse les conversions qui perdent de l'information (`Point p{3.7, 4};` est une erreur, alors que `Point p(3.7, 4);` tronque 3.7 en 3). [[Complément hors du cours|ⓘ]]

### Plusieurs constructeurs dans une classe

```cpp
class Point {
private:
    int x, y;
public:
    Point() {
        x = 0;
        y = 0;
    }
    Point(int a, int b) {
        x = a;
        y = b;
    }
};
```

1. `Point a;` : aucun argument, le compilateur choisit le constructeur par défaut `Point()`. Résultat : `x = 0`, `y = 0`.
2. `Point b(3, 4);` : deux arguments, c'est `Point(int a, int b)` qui est appelé. Résultat : `x = 3`, `y = 4`.

> **Attention** : dès qu'on définit un constructeur, le compilateur **ne génère plus** de constructeur par défaut. Avec seulement `Point(int, int)`, l'écriture `Point a;` ne compile plus.

Deux façons de garder `Point a;` sans écrire un second constructeur complet : `Point() = default;` (C++11) redemande au compilateur le constructeur par défaut qu'il aurait généré, et des **valeurs par défaut** des paramètres, `Point(int a = 0, int b = 0)`, font qu'un seul constructeur accepte `Point a;`, `Point b(3);` et `Point c(3, 4);`. Choisir un constructeur d'après le nombre et le type des arguments est un cas de **surcharge de fonctions** : plusieurs fonctions de même nom, distinguées par leurs paramètres. [[Complément hors du cours|ⓘ]]

### Le constructeur par copie

Il crée un nouvel objet à partir d'un objet existant du même type. L'objet à copier est reçu en paramètre, **par référence constante** (voir [[Référence (C++)]]).

```cpp
class Point {
private:
    int x, y;
public:
    Point(const Point& autre);
};

// constructeur par copie
Point::Point(const Point& autre) {
    x = autre.x;
    y = autre.y;
}

Point p0;
Point p1(3, 4);
Point p2(p1);
```

`Point(const Point& autre)` est appelé : chaque coordonnée de `p1` est recopiée dans `p2`, qui vaut donc aussi (3, 4).

Le paramètre **doit** être une référence : reçu par valeur, `autre` serait lui-même une copie, dont la création appellerait le constructeur par copie, qui appellerait à nouveau le constructeur par copie, sans fin. Le compilateur refuse donc `Point(Point autre)`. Le `const` permet en plus de copier un objet constant. Le constructeur peut lire `autre.x` bien que `x` soit privé : l'accès privé est accordé par classe, pas par objet, donc toute méthode de `Point` accède aux attributs privés de n'importe quel `Point`. [[Complément hors du cours|ⓘ]]

### Copie : fonctionnement et usages

- **Fourni par le compilateur** : si on n'écrit pas de constructeur par copie, le compilateur en génère un, qui recopie chaque attribut un par un.
- **Deux objets indépendants** : après la copie, modifier `p2` ne change pas `p1` (et inversement).

```cpp
Point p1(3, 4);
Point p2 = p1;          // copie : p2 = (3, 4)
Point p3(p1);           // idem

p2.x = 10;              // modifie seulement p2
std::cout << p1.x;      // 3 (p1 inchangé)
std::cout << p2.x;      // 10
```

**Quand la copie a-t-elle lieu ?**
- à l'initialisation : `Point p2 = p1;` ;
- au passage par valeur d'un paramètre de fonction (voir [[Passage par valeur]]) ;
- au retour d'une fonction par valeur.

En revanche, `p2 = p1;` entre deux objets **déjà créés** n'appelle pas le constructeur par copie mais l'**opérateur d'affectation** `operator=`, lui aussi généré par le compilateur. Le signe `=` dans `Point p2 = p1;` est une initialisation, pas une affectation. [[Complément hors du cours|ⓘ]]

La copie attribut par attribut générée par le compilateur est une **copie superficielle** : si un attribut est un [[Pointeur et adresse mémoire|pointeur]] vers une zone obtenue par [[Allocation dynamique|allocation dynamique]] (`new`), les deux objets pointent ensuite vers la **même** zone, et la modifier par l'un modifie l'autre. Il faut alors écrire soi-même une **copie profonde**, qui alloue une nouvelle zone et y recopie le contenu. [[Complément hors du cours|ⓘ]]

Le pendant du constructeur est le **destructeur**, `~Point()`, sans paramètre ni type de retour, appelé automatiquement quand l'objet disparaît (fin du bloc où il est déclaré, `delete`). Il sert à libérer ce que l'objet a acquis (mémoire, fichier ouvert). D'où la **règle de trois** : une classe qui a besoin d'un destructeur écrit à la main a presque toujours besoin aussi d'un constructeur par copie et d'un opérateur d'affectation écrits à la main. Pour `Point`, qui ne contient que des `int`, les versions générées suffisent. Voir [[Destructeur (programmation)]]. [[Complément hors du cours|ⓘ]]

### Fonctions membres : exemple d'affichage

On souhaite écrire une fonction d'affichage pour la classe `Point`, appelée par `p1.affiche();`. Le cours procède en trois diapositives : la classe avec ses trois constructeurs, puis on ajoute la déclaration `void affiche();` dans la classe, puis on écrit sa définition hors de la classe, préfixée par `Point::`.

```cpp
class Point {
private:
    int x, y;
public:
    Point();
    Point(int a, int b);
    Point(const Point& autre);
    void affiche();
};

void Point::affiche() {
    std::cout << "x: " << x << std::endl;
    std::cout << "y: " << y << std::endl;
}

Point p1(3, 4);
p1.affiche();
```

La dernière diapositive esquisse aussi une méthode booléenne : `if (p1.est_positif()) {…}`.

Déclarer dans la classe et définir dehors prépare le découpage en fichiers d'un vrai projet : la classe (les déclarations) va dans un **[[Fichier d'en-tête|fichier d'en-tête]]** `point.h`, les définitions `Point::…` dans `point.cpp`, et tout fichier qui utilise `Point` fait `#include "point.h"`. Une méthode définie directement dans la classe, comme les constructeurs de la section précédente, est implicitement `inline`. [[Complément hors du cours|ⓘ]]

Une méthode qui ne modifie pas l'objet se déclare **`const`**, après la parenthèse : `void affiche() const;` et `void Point::affiche() const { … }`. Le compilateur vérifie alors qu'elle ne change aucun attribut, et elle devient appelable sur un objet constant, par exemple le `const Point& p` reçu par `operator<<` plus bas. [[Complément hors du cours|ⓘ]]

Dans une méthode, `x` désigne l'attribut de l'objet sur lequel la méthode est appelée : `p1.affiche()` affiche `p1.x`. Cet objet est accessible par le pointeur **`this`** ; `x` est un raccourci de `this->x` (voir [[Opérateur flèche]]). On l'écrit explicitement quand un paramètre porte le même nom qu'un attribut : `void setX(int x) { this->x = x; }`. [[Complément hors du cours|ⓘ]]

Une version possible de la méthode esquissée, qui teste si le point a deux coordonnées positives : `bool Point::est_positif() const { return x >= 0 && y >= 0; }`. [[Complément hors du cours|ⓘ]]

## 6. Accéder aux données privées : get et set

Puisqu'une donnée privée n'est pas accessible directement, on définit des méthodes publiques dédiées : l'**accesseur** (*get*) pour la lire, et le **mutateur** (*set*) pour la modifier (voir [[Accesseur et mutateur]]).

```cpp
class CompteBancaire {
private:
    double solde;

public:
    double getSolde() {
        return solde;
    }

    void setSolde(double s) {
        solde = s;
    }
};
```

- `getSolde()` renvoie la valeur actuelle de `solde`, sans la modifier.
- `setSolde(s)` reçoit une nouvelle valeur `s` et met à jour `solde`, en pouvant **vérifier qu'elle est valide**.
- Exemple de vérification : `void setSolde(double s) { if (s >= 0) solde = s; }` refuse un solde négatif et laisse l'ancien. Un accesseur se déclare en général `const` : `double getSolde() const`. [[Complément hors du cours|ⓘ]]

### Exemple : la classe `Personne`

```cpp
class Personne {
private:
    std::string nom;
    int age;

public:
    void setNom(std::string n) {
        nom = n;
    }
    void setAge(int a) {
        age = a;
    }
    int getAge() { return age; }
};

Personne p;
p.setNom("Léo");
p.setAge(30);

std::cout
    << p.getAge()
    << std::endl;
// affiche : 30
```

On crée un objet `Personne`, puis on passe uniquement par ses accesseurs pour lire ou modifier son âge, jamais directement. **Remarque du cours** : l'exemple n'est pas complet, il manque les constructeurs.

## 7. Surcharge d'opérateurs

Voir [[Surcharge d'opérateurs]].

Écrire un opérateur n'est qu'une autre façon d'appeler une fonction : pour une méthode, le compilateur traduit `-p1` en `p1.operator-()` et `p1 + p2` en `p1.operator+(p2)`. L'objet de gauche est celui sur lequel la méthode est appelée, l'objet de droite le paramètre. On ne peut ni inventer un opérateur, ni changer le nombre d'opérandes, la priorité ou l'associativité d'un opérateur existant, ni surcharger un opérateur entre types de base ; quelques opérateurs ne se surchargent pas du tout (`::`, `.`, `?:`, `sizeof`). [[Complément hors du cours|ⓘ]]

### Opérateur unaire : `operator-`

Un opérateur unaire agit sur un seul objet (ex. `-x`). En C++, on peut redéfinir son comportement pour ses propres classes grâce à la surcharge d'opérateurs.

```cpp
class Point {
private:
    int x, y;

public:
    Point operator-() {
        return Point{-x, -y};
    }
};

Point p1{3, 4};
Point p2 = -p1; // (-3, -4)
```

`operator-()` est appelée automatiquement : elle renvoie un nouveau `Point` aux coordonnées opposées. `return Point(-x, -y);` appelle le constructeur par paramètres de la classe `Point`, avec les paramètres `-x` et `-y`.

### Opérateur binaire : `operator+`

Un opérateur binaire relie deux objets (ex. `a + b`). On peut définir ce que signifie « additionner » deux objets de sa propre classe. Comme `x` est privé, `main` le lit par un accesseur `getX()` (écrire `p3.x` hors de la classe ne compile pas) : [[Erreurs du cours#^e-4-c|✎]]

```cpp
class Point {
private:
    int x, y;

public:
    Point operator+(Point autre) {
        return Point{x + autre.x,
                     y + autre.y};
    }
    int getX() const { return x; }
};

Point p3 = p1 + p2;
std::cout << p3.getX(); // 0
```

`operator+(Point autre)` additionne les coordonnées `x` et `y` des deux points, terme à terme. `return Point(x + autre.x, y + autre.y);` appelle le constructeur par paramètres. Avec les `p1 = (3, 4)` et `p2 = (-3, -4)` de la diapositive précédente, `p3 = (0, 0)`.

Forme usuelle : `Point operator+(const Point& autre) const`. La référence constante évite de copier l'opérande de droite, et le `const` final indique que `p1 + p2` ne modifie pas `p1`, ce qu'on attend d'une addition. À l'inverse, `operator+=` (`p1 += p2`) modifie l'objet de gauche et renvoie une référence sur lui (`Point&`). [[Complément hors du cours|ⓘ]]

### Afficher un objet : `operator<<`

Pour que `std::cout << p` fonctionne avec ses propres objets, on surcharge l'opérateur d'affichage `<<` pour la classe `Point`.

```cpp
class Point {
private:
    int x, y;
public:
    friend std::ostream& operator<<(std::ostream& os, const Point& p) {
        os << "(" << p.x << ", " << p.y << ")";
        return os;
    }
};

Point p{3, 4};
std::cout << p; // Affiche : (3, 4)
```

`operator<<` est appelée automatiquement : elle écrit « (3, 4) » dans le flux de sortie.

Le `return os;` permet d'enchaîner : `std::cout << p1 << p2;` se lit `(std::cout << p1) << p2`, et le premier appel renvoie le flux, sur lequel s'applique le second. C'est aussi pourquoi le type de retour est une référence `std::ostream&` : un flux ne se copie pas. [[Complément hors du cours|ⓘ]]

**Les paramètres, passés par référence** (voir [[Référence (C++)]]) :

| Paramètre | Rôle |
|---|---|
| `std::ostream& os` | référence à un flux de sortie (par exemple `std::cout`) : c'est dans ce flux qu'on écrit avec `<<` |
| `const Point& p` | référence constante à un objet `Point` : l'objet qu'on veut afficher |

Avantages du passage par référence : il **évite la copie** de l'objet (plus efficace) et **permet de modifier l'objet original** (si non `const`).

**Pourquoi `friend` ?** (voir [[Fonction amie (friend)]]) L'opérateur `<<` n'est pas une méthode de `Point`, mais il doit lire `x` et `y`, qui sont privés.
1. `std::cout` est externe à `Point` : l'opérateur est appelé sur le flux `std::cout`, qui n'appartient pas à la classe.
2. Impossible de modifier `std::ostream` : on ne peut pas lui ajouter de méthode, donc `operator<<` est écrit en dehors des classes.

Sans `friend`, `operator<<` ne pourrait pas accéder à `x` et `y`. Avec `friend`, il accède aux membres privés de `Point`.

**Pourquoi `const` pour `Point` ?**
- `const Point& p` : l'objet n'est pas modifié, on se contente de lire ses coordonnées ; `const` protège contre les modifications accidentelles.
- `std::ostream& os` n'est pas `const` : on écrit dedans avec `<<`, le flux est donc modifié.

**Afficher un tableau 1D en 2D** (aide donnée par le cours ; le modulo est le nombre de colonnes, 21, et `for`, `cout` s'écrivent en minuscules) : [[Erreurs du cours#^e-4-c|✎]]

```cpp
int tableau[21*12];

//exemple d' affichage en 21 par 12 d'un tableau en 1 dimension
//on utilise le modulo du nombre de colonnes
for (i=0;i<21*12;i++){
     if (i % 21 == 0) cout<<endl;
     cout<<tableau[i]<<"  ";
}
```

La case de ligne `l` et de colonne `c` est à l'indice `l * 21 + c` ; on passe à la ligne quand l'indice est un multiple du nombre de colonnes, 21.

Dans l'autre sens, la case d'indice `i` est à la ligne `i / 21` (quotient entier) et à la colonne `i % 21`. Ranger un tableau 2D ligne après ligne dans un tableau 1D est l'**ordre ligne par ligne** (*row-major order*), celui qu'utilise le C++ pour ses propres tableaux à deux dimensions.
