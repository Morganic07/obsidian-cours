Selon la prise de notes de culture du vivant, le Web a été inventé par Tim Berners-Lee (date notée : 1993) ; anarchiste à l'origine, il est devenu capitaliste. Berners-Lee travaille au web 3.0, sémantique. Sur le web actuel, un moteur cherche une chaîne de caractères et se fonde sur la co-occurrence statistique des mots.

Voir aussi : [[Web sémantique]], [[Capitalisme]].

## À vérifier

- Le web est généralement daté de 1989-1991 ; la note donne 1993, peut-être la mise dans le domaine public (relevé du résumé).
- Les termes « World Wide Web » et « WWW » ne figurent pas dans la note, qui dit « Web ».
