Un complexe s'écrit $z = a + ib$ avec $i^2 = -1$. Conjugué $\bar{z} = a - ib$, et $z\bar{z} = a^2 + b^2 = |z|^2$.

- **Trinôme** $az^2 + bz + c$ : toujours résoluble dans $\mathbb{C}$ ; si $\Delta < 0$, racines conjuguées $\frac{-b \mp i\sqrt{-\Delta}}{2a}$.
- **Forme trigonométrique** : $z = |z|(\cos\theta + i\sin\theta)$, $\theta = \arg(z)$ modulo $2\pi$. Module multiplicatif, arguments additifs pour un produit.
- **Forme exponentielle** : $z = |z|e^{i\theta}$.
- **Moivre** : $z^n = |z|^n(\cos n\theta + i\sin n\theta)$. **Euler** : $\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}$, $\sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}$.
- **Géométrie** : $|z_B - z_A| = AB$, $\arg(z_B - z_A) = (\vec{u}; \overrightarrow{AB})$.

Le cours écrit à tort $|\cos\theta + \sin\theta| = 1$ (il manque le $i$) et $\cos 2x = 1 - \sin^2 x$ (il faut $1 - 2\sin^2 x$).
