Une distribution est un ensemble de paquets logiciels regroupés pour l'installation : le [[Noyau]] Linux, plus un système de fenêtres, un environnement de bureau et des applications. Exemples : Ubuntu, Debian, Fedora, Arch Linux, CentOS, openSUSE.

**Ubuntu** : libre, la distribution la plus populaire, appréciée pour sa simplicité, sa stabilité et ses fonctions. Deux versions : Desktop (interface graphique) et Server (ligne de commande). Deux types de publication : **LTS** (support long, 3-4 ans selon le cours, stable) et *interim* (support court de 9 mois, pour tester les nouveautés).

**Installation** : une image ISO (copie exacte d'un disque optique) est nécessaire. Sur PC : clé USB bootable (par exemple avec Rufus) puis démarrage dessus. Sur machine virtuelle : VirtualBox (hôte Windows) ou KVM (hôte Ubuntu), sans clé bootable (voir [[Machine virtuelle]]).
