Notation $x \equiv y\ [\theta]$ : il existe $k \in \mathbb{Z}$ tel que $x = y + k\theta$. Alors :

- $\sin x = \sin y \iff x \equiv y\ [2\pi]$ ou $x \equiv \pi - y\ [2\pi]$ ;
- $\cos x = \cos y \iff x \equiv \pm y\ [2\pi]$ ;
- $\tan x = \tan y \iff x \equiv y\ [\pi]$.

Exemple du cours : $\sin x = \cos x \iff x \equiv \pi/4\ [\pi]$.

**Méthode des corrigés** : donner d'abord l'ensemble de définition, puis se ramener à $\sin a = \sin b$ ou factoriser.
