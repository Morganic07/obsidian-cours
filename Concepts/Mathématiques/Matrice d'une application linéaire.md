La matrice de $f$ dans les bases $B$ et $B'$ a pour colonne $j$ les coordonnées dans $B'$ de l'image par $f$ du $j$-ième vecteur de $B$.

La matrice de la composée est le produit : $M_{g \circ f} = M_g \times M_f$. Changer de base change la matrice : $A' = P^{-1}AP$.

Notion parente : [[Matrice]]. Voir aussi : [[Transformation linéaire]], [[Changement de base]], [[Produit matriciel]], [[Coordonnées dans une base]], [[Composition de fonctions]].

Dans le document chp4, les sections « Matrice d'une application », « Calcul de l'image d'un vecteur » et « Application » sont vides (les formules annoncées par « Dans cette base, on note » et « Si je note » n'y figurent pas).

## Erreurs du cours

- [[4 - Algèbre linéaire|chp4]] écrit « la matrice M<sub>n,p</sub>(lR) dont les colonnes sont les coordonnées dans B' des vecteurs de B » ; il faut « les coordonnées dans $B'$ des **images par $f$** des vecteurs de $B$ ». Le même chapitre le dit plus loin : « la matrice a pour colonne (j) les images des vecteurs de la base ».
