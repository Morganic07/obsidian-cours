Une base d'un sous-espace $H$ est un ensemble de vecteurs linéairement indépendants de $H$ qui engendre $H$.

- Les colonnes d'une matrice $n \times n$ inversible forment une base de $\mathbb{R}^n$.
- La base standard de $\mathbb{R}^n$ est formée des colonnes $\mathbf{e}_1, \dots, \mathbf{e}_n$ de $I_n$.
- Dans un espace de dimension $p$, tout ensemble de $p$ vecteurs indépendants est une base.
- Le sous-espace $\{\mathbf{0}\}$ n'a pas de base.
- De toute famille génératrice, on peut extraire une base.
- **Théorème de la base incomplète** : toute famille libre peut être complétée en une base.
- $n$ vecteurs forment une base si et seulement si le déterminant de la matrice de leurs composantes est non nul.
- Une application bijective envoie une base sur une base.
- En Algèbre Linéaire (1re année), une base est une famille libre et génératrice ; en dimension $n$, toute base a $n$ vecteurs, et une famille libre ou génératrice de $n$ vecteurs est une base.

Les évaluations 2 et 3 de 1re année portent sur une base de $\mathbb{R}^3$, des bases de sous-espaces et les coordonnées dans une base de $\mathbb{R}^3$ ([[Raw/Year 1/Contrôles.pdf|Contrôles]]).
