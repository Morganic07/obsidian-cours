Innovation de procédé (Linus Torvalds, 2005), selon un devoir de management de l'innovation : un contrôle de version décentralisé, où chaque développeur possède l'historique complet.

En SHS, maîtriser Git et Python est cité comme condition pour contribuer à OpenFisca (voir [[Gouvernance par l'expertise]]).
