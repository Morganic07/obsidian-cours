Chaque geste numérique repose sur des architextes qui exécutent du code et formatent nos actions selon des choix programmés. Le code intervient dans l'énonciation : données, formats, métadonnées, logs, feuilles de style.

Désenfouir le code, c'est faire apparaître cette écriture cachée : le fil n'est pas chronologique mais algorithmique, les likes quantifient le social, les suggestions sont des inférences, les stories imposent une temporalité programmée.
