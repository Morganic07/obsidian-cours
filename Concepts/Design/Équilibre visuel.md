Glossaire d'anglais :

- **Balance** : formes, couleurs, lignes, textures et espaces bien répartis pour créer une stabilité visuelle ;
- **Radial balance** : proche de la symétrie, les parties égales rayonnent depuis le centre ;
- **Crystallographic** (ou **mosaic**) **balance** : équilibre créé en répétant les mêmes éléments ;
- **Visual weight** : force visuelle d'un élément ;
- **Axis** : ligne imaginaire le long de laquelle on dispose les éléments ;
- **Asymmetrical** : deux moitiés qui ne se reflètent pas.
