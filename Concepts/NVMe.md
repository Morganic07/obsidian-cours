Non-Volatile Memory Express : interface surtout utilisée pour les SSD, à connexion extrêmement rapide, souvent via PCIe ; 32 Gbps dans le tableau du cours.

Notion parente : [[Interface de stockage]]. Voir aussi : [[SSD]], [[PCI Express]], [[M.2]].
