Glossaire d'anglais :

- **User journey** : parcours de l'utilisateur tout au long du service, pour comprendre ses besoins ;
- **Pain point** : point négatif qui apparaît pendant le parcours et peut ouvrir des opportunités ;
- **User flow** : enchaînement d'écrans par lequel l'utilisateur est guidé ;
- **Customer needs** : ce que désirent les clients, mais aussi ce que l'on pense pouvoir les aider.

**Affordance** : la construction des *user journeys* est une étape du projet fil rouge et un usage possible des analyses d'observation ; le test utilisateur analyse des parcours-types (points d'entrée, usage du menu). Le cours ne le définit pas davantage.
