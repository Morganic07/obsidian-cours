**Définition (complément, hors du cours)** : sur un [[Espace vectoriel]] $E$ sur un [[Corps (algèbre)|corps]] $K$, une forme linéaire est une application linéaire de $E$ dans $K$ : $\varphi(\lambda x+\mu y)=\lambda\varphi(x)+\mu\varphi(y)$ pour tous vecteurs $x, y$ et scalaires $\lambda, \mu$. Elle renvoie donc un scalaire, pas un vecteur. Sur $\mathbb{R}^n$, les formes linéaires sont exactement les applications $\varphi(\mathbf{x})=\mathbf{a}\cdot\mathbf{x}=a_1x_1+\dots+a_nx_n$, pour un vecteur $\mathbf{a}$ fixé.

## Dans le cours

Nommé dans [[chp 2 - Symmetric matrices and quadratic forms (résumé)|Chp2 - Symmetric matrices and quadratic forms]] sans définition : le cours cite « $f(\mathbf{x},\mathbf{y})=\mathbf{x}+\mathbf{y}$ (linear form) » pour l'opposer à la [[Forme bilinéaire]].

Notion parente : [[Transformation linéaire]]. Voir aussi : [[Forme bilinéaire]].

## À vérifier

Exemple apparemment erroné : $\mathbf{x}+\mathbf{y}$ est un vecteur, pas un scalaire ; le cours ne donne pas de définition correcte.
