Dans une base $(e_1, \ldots, e_n)$, tout $x$ s'écrit de façon unique $x = \lambda_1 e_1 + \ldots + \lambda_n e_n$ : les $\lambda_i$ sont ses coordonnées (ou composantes).

Si une famille est une base, il existe une bijection qui associe à tout vecteur ses composantes dans cette base ; le choix d'une base identifie $E$ à $\mathbb{K}^n$. Après un [[Changement de base]] de matrice de passage $P$, les nouvelles coordonnées sont $X' = P^{-1}X$.

Notion parente : [[Base (algèbre linéaire)]]. Voir aussi : [[Matrice d'une application linéaire]].

## À vérifier

- chp4 : la section « Matrice d'un vecteur » s'arrête sur « Dans cette base, on note » (vide dans l'export).
- chp5 écrit « $X^{-1} = P^{-1} \cdot X$ » ; il faut lire $X' = P^{-1}X$.
