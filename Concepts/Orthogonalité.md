Deux vecteurs sont orthogonaux si $\mathbf{u} \cdot \mathbf{v} = 0$, ou de façon équivalente si $\|\mathbf{u} + \mathbf{v}\|^2 = \|\mathbf{u}\|^2 + \|\mathbf{v}\|^2$ (Pythagore). $(\text{Row } A)^\perp = \text{Nul } A$ et $(\text{Col } A)^\perp = \text{Nul } A^T$.
