**Définition (complément, hors du cours)** : Unicode est la norme qui attribue un numéro unique, le point de code (noté `U+0041` pour « A »), à chaque caractère de la quasi-totalité des écritures du monde, ainsi qu'aux symboles et emojis. Ses 128 premiers points de code reprennent le [[Code ASCII]]. Les points de code sont ensuite représentés en mémoire par un codage : UTF-8 (1 à 4 octets, le plus répandu sur le web), UTF-16 (unités de 16 bits, celles du `char` de Java ; un caractère hors du plan de base en occupe deux) ou UTF-32.

## Dans le cours

Nommé dans [[chp 1 - Intro Java (résumé)|Chp1 - Intro Java]] sans définition : le cours indique seulement que le type `char` de Java est codé sur 16 bits en Unicode.
