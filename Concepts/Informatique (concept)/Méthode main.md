Toute application Java doit avoir une méthode `main`, exécutée en premier. Le fichier porte le nom de la classe (`Premier.java`). Les arguments de la ligne de commande arrivent dans un tableau (`args[0]`), converti au besoin par `Double.parseDouble` ([[1 - Intro Java (résumé)|Chp1 - Intro Java]]).
