Architectures d'accès à une base de données (tier = niveau) :

- **client-serveur 2 tiers** : application console ou graphique et SGBD ;
- **web 3 tiers** : navigateur, serveur web, SGBD ;
- **4 tiers ou plus** : avec un serveur d'application.

Ces architectures peuvent tourner en local. Le projet de ligue de football demande un schéma d'architecture.
