Mode de financement cité dans les notes SHS d'un groupe d'étudiants, avec Vault et les dons. Selon leur plan, chez Blush.design ou Figma, le modèle freemium confisque les vrais fichiers de design (SVG, code source des composants) derrière un mur payant et interdit la revente de produits dérivés. Un enseignant a jugé que le groupe insistait trop sur le freemium.
