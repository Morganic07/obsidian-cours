Les neuf dimensions de Spradley servent à croiser les observations : d'abord les grands tours (quels sont les espaces, les acteurs…), puis les mini-tours, qui croisent les neuf dimensions en matrices. Les neuf dimensions ne sont pas énumérées dans la note.

**Les neuf dimensions (complément, hors du cours)** : l'anthropologue James Spradley les propose dans *Participant Observation* (1980) pour décrire toute situation sociale.

| Dimension | Ce qu'on observe |
|---|---|
| Espace (*space*) | le ou les lieux physiques |
| Acteurs (*actor*) | les personnes impliquées |
| Activité (*activity*) | un ensemble d'actes liés entre eux |
| Objet (*object*) | les choses physiques présentes |
| Acte (*act*) | une action isolée |
| Événement (*event*) | un ensemble d'activités |
| Temps (*time*) | le déroulement, l'enchaînement dans le temps |
| But (*goal*) | ce que les personnes cherchent à accomplir |
| Sentiment (*feeling*) | les émotions ressenties et exprimées |

Les mini-tours croisent ces dimensions deux à deux dans une matrice de 9 × 9 cases, chaque case donnant une question : par exemple, comment l'espace est-il organisé par les objets ? quels sentiments accompagnent tel événement ?
