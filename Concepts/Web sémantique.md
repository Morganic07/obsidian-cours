Selon le cours de Culture du vivant (4e année), Tim Berners-Lee travaille sur un « web 3.0 » sémantique, le web étant à l'origine anarchiste puis devenu capitaliste.

Différence donnée en exemple avec « Ada Lovelace » :

- **Web actuel** : le moteur cherche la chaîne de caractères et s'appuie sur la co-occurrence statistique des mots ; un homonyme le trouble.
- **Web sémantique** : les données sont des triplets (sujet, prédicat, objet) ; un agent logiciel sait que la personne est mathématicienne, liée à la machine analytique de Babbage, et comprend le réseau de relations.

Le cours oppose aussi IA sémantique et IA générative, sans développer.
