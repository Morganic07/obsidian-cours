Une relation binaire $\mathcal{R}$ sur $E$ est une propriété reliant deux éléments, ou une partie de $E \times E$. Elle peut être réflexive, symétrique, antisymétrique, transitive.

**Relation d'équivalence** (notée $\sim$) : réflexive, symétrique, transitive. La **classe** d'un élément est $[x] = \{y \in E \mid x \sim y\}$. L'**ensemble quotient** $E/R = \{[a] \mid a \in E\}$ regroupe les classes. Une classe se dit « avoir le même (propriété) ».

Le cours ne le dit pas, mais les classes forment une partition de $E$ (complément ; voir [[Opérations sur les ensembles]]).
