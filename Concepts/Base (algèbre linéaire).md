Une base d'un sous-espace $H$ est un ensemble de vecteurs linéairement indépendants de $H$ qui engendre $H$.

- Les colonnes d'une matrice $n \times n$ inversible forment une base de $\mathbb{R}^n$.
- La base standard de $\mathbb{R}^n$ est formée des colonnes $\mathbf{e}_1, \dots, \mathbf{e}_n$ de $I_n$.
- Dans un espace de dimension $p$, tout ensemble de $p$ vecteurs indépendants est une base.
- Le sous-espace $\{\mathbf{0}\}$ n'a pas de base.
