Le chp 1 distingue plusieurs environnements informatiques :

- **traditionnel** : machine autonome généraliste (PC, portable) ;
- **mobile** : smartphone riche en capteurs comme le GPS et le gyroscope, avec de nouvelles applications comme la réalité augmentée et les données cellulaires ; les leaders sont iOS et Android ([[Multitâche sur mobile]]) ;
- **virtuel** ([[Machine virtuelle]]) ;
- **client-serveur** ([[Modèle client-serveur]]) ;
- **cloud** ([[Cloud computing]]) ;
- **systèmes distribués** ([[Système distribué]]).
