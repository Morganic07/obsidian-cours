**Définition (complément, hors du cours)** : Vim (*Vi IMproved*) est un [[Éditeur de texte|éditeur de texte]] en mode terminal, version améliorée de l'éditeur vi des systèmes Unix. Il fonctionne par modes : le mode normal, où les touches sont des commandes de déplacement et d'édition ; le mode insertion (touche `i`), où l'on tape du texte ; le mode ligne de commande (touche `:`), par exemple `:w` pour enregistrer et `:q` pour quitter. `Échap` ramène au mode normal. Plus difficile à prendre en main qu'[[Éditeur nano|nano]], il est très efficace une fois maîtrisé.
