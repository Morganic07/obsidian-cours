**Définition (complément, hors du cours)** : GitHub est une plateforme d'hébergement de dépôts [[Git]], lancée en 2008 et rachetée par Microsoft en 2018. Elle ajoute à Git des outils de collaboration : propositions de modification (*pull requests*), suivi des problèmes, revue de code, intégration continue. C'est aujourd'hui la principale forge du [[Logiciel libre|logiciel libre]], bien qu'elle soit elle-même un service propriétaire.

## Dans le cours

Dans [[6 - design libre]], GitHub est cité parmi les lieux de « vrai design libre », où les fichiers partagés sont du [[Code source|code source]].

Voir aussi : [[Git]], [[Communs numériques]].
