Small Computer System Interface : interface de stockage souvent utilisée pour les serveurs et les stations de travail. Sa version plus récente est [[SAS (interface de stockage)|SAS]].

Débit : jusqu'à 320 MB/s pour l'Ultra-320, la plus rapide des versions parallèles commercialisées (l'Ultra-640, normalisée en 2003 sous le nom SPI-5, n'a pas été produite) ; c'est moins que les 12 Gb/s du SAS. [[Erreurs du cours#^e-scsi|✎]]

Notion parente : [[Interface de stockage]].
