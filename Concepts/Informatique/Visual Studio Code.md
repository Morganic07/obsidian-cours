**Définition (complément, hors du cours)** : [[Éditeur de texte|éditeur de code]] gratuit et multiplateforme publié par [[Microsoft]] en 2015, dont le cœur est libre (licence MIT). Il devient un quasi-[[Environnement de développement intégré|EDI]] par extensions : pour le C++, l'extension C/C++ apporte complétion, compilation via g++ ou Clang et débogage (GDB). C'est l'éditeur le plus utilisé par les développeurs dans les enquêtes Stack Overflow depuis 2018.
