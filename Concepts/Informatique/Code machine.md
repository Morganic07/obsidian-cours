**Définition (complément, hors du cours)** : suite d'instructions binaires directement exécutables par un [[Processeur|processeur]], propre à son jeu d'instructions (x86-64, ARM…). C'est ce que produit le [[Compilateur|compilateur]] à partir du [[Code source|code source]] ; le [[Langage d'assemblage|langage d'assemblage]] en est la forme lisible, une instruction par ligne. Un code machine n'est pas [[Portabilité (informatique)|portable]] d'une architecture ou d'un système à l'autre.

## Dans le cours

[[4 - Cours complet]] emploie comme synonymes « exécutable, code objet ou code machine » pour ce que l'ordinateur exécute ; le [[Fichier objet|fichier objet]] contient du code machine, mais il faut encore l'[[Édition de liens|édition de liens]] pour obtenir un [[Exécutable|exécutable]].
