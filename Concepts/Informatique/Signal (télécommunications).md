**Définition (complément, hors du cours)** : grandeur physique variable (tension électrique, onde radio, impulsion lumineuse, son) qui porte une [[Information|information]] d'un émetteur vers un récepteur. Dans le schéma de Shannon (1948), une source produit un message, un émetteur le code en signal, le signal traverse un canal où il subit du bruit, puis un récepteur le décode pour le destinataire. Un signal peut être analogique (variation continue, comme la voix au [[Téléphone|téléphone]]) ou numérique (suite de valeurs discrètes, comme les [[Bit|bits]]). [[Complément hors du cours|ⓘ]]
