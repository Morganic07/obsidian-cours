CLI (command line interface) : le DM définit le shell comme une interface en ligne de commande qui permet d'interagir avec le système. Elle s'oppose à l'[[Interface graphique]] (GUI).

Notion parente : [[Shell et Bash]].

[[2 - Histoire du design]] : avec l'Alto, l'ordinateur n'est plus seulement une machine à laquelle on donne des instructions spécialisées ; avant le Web, Internet = lignes de commande + protocoles.
