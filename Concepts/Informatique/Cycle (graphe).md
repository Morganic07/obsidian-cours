**Algo** : dans un graphe non orienté, une chaîne $(u_0,\dots,u_k)$ forme un cycle si $k \ge 2$ et $u_0=u_k$ ; le cycle est **élémentaire** si ses sommets sont distincts. Un graphe sans cycle est dit **acyclique**. Exemple : a-b-e-a, cycle de longueur 3.

**graph theory** : chaîne simple $C = (v_0, e_1, \ldots, e_p, v_p)$ de longueur $\ell(C) > 0$ avec $v_p = v_0$.
