Autrefois les systèmes d'exploitation fonctionnaient en CLI ; aujourd'hui ils ont des GUI. GUI et CLI sont deux moyens de lancer un programme. Ubuntu Desktop a une GUI, Ubuntu Server une CLI ; l'UEFI offre une GUI de configuration, pas le BIOS.

Notion parente : [[Système d'exploitation]]. Voir aussi : [[Interface en ligne de commande]], [[BIOS et UEFI]], [[Ubuntu]].
