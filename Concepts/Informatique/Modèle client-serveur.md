Le cours distingue deux types de serveurs :

- le **serveur de calcul** (compute server) offre une interface pour demander un service, par exemple une base de données MySQL ou PostgreSQL qui traite une requête et renvoie le résultat ;
- le **serveur de fichiers** (file-server system) permet de stocker et de récupérer des fichiers (Google Drive).

Notion parente : [[Environnement informatique]]. Voir aussi : [[Cloud computing]], [[Système distribué]].

[[2 - Histoire du design]] : le Web permet de consulter une toile de documents hypertextes à travers une architecture client-serveur ; schéma des requêtes HTTP entre navigateur et serveur.
