**Définition (complément, hors du cours)** : procédé qui ajoute à des données une [[Redondance (théorie de l'information)|redondance]] calculée pour pouvoir détecter, et parfois corriger, les erreurs survenues pendant la transmission ou le stockage. Le plus simple, le bit de parité, signale qu'un nombre impair de [[Bit|bits]] a changé sans dire lesquels ; les codes de Hamming (1950) corrigent une erreur par bloc ; les codes de Reed-Solomon (1960) protègent les CD, les QR codes et les transmissions spatiales. Shannon a montré en 1948 qu'on peut transmettre de façon fiable sur un canal bruité, tant qu'on reste sous sa capacité ([[Théorie de l'information]]). [[Complément hors du cours|ⓘ]]

## Dans le cours

[[2 - De courrier à courriels]] : les utilisateurs des messageries ont inventé leurs propres « procédures de correction d'erreurs a posteriori » (le mot rectifié dans un message séparé, précédé d'un astérisque) ; complément sur les codes correcteurs, qui ajoutent de la redondance.
