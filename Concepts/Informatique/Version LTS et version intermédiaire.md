**Définition (complément, hors du cours)** : une distribution comme [[Ubuntu]] publie deux sortes de versions : des versions LTS, maintenues (correctifs de sécurité et de bogues) pendant plusieurs années, et des versions intermédiaires, qui apportent plus vite les nouveautés mais ne sont maintenues que quelques mois.

- **LTS** (long term support) : publication majeure, stable et supportée longtemps (3 à 4 ans selon le cours), pour qui veut un système fiable.
- **Interim release** (version intermédiaire) : moins stable, pour tester les nouvelles fonctions, avec un support court (9 mois).

## Calendrier d'Ubuntu (complément, hors du cours)

- Une version sort tous les six mois, en avril et en octobre ; elle est numérotée `AA.MM` d'après sa date de sortie : 24.04 = avril 2024, 24.10 = octobre 2024. Une mise à jour corrective d'une LTS porte un troisième numéro (24.04.1).
- Une LTS sort tous les deux ans, en avril des années paires (20.04, 22.04, 24.04) ; les trois versions intermédiaires entre deux LTS durent chacune 9 mois.
- Depuis la 12.04, Canonical annonce **5 ans** de mises à jour standard pour chaque LTS, version Desktop comme Server ; l'abonnement **Ubuntu Pro** (gratuit pour un usage personnel sur quelques machines) prolonge la maintenance de sécurité au-delà, jusqu'à 10 ans, voire 12 avec une option supplémentaire.

Désaccord entre les sources : le cours ([[Raw/Year 2/Operating System/Cours OS/OS - chp 3.docx|OS - chp 3]]) donne 3 à 4 ans de support à une LTS ; le calendrier publié par Canonical donne 5 ans de support standard depuis la 12.04. Les 3 ans correspondent aux anciennes LTS Desktop (jusqu'à la 10.04), qui n'avaient que 3 ans contre 5 pour la version Server.
