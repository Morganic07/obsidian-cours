**Définition (complément, hors du cours)** : texte d'un programme tel que l'écrivent les programmeurs, dans un langage lisible par un humain (C, Python, JavaScript…), avant sa traduction en code machine par un compilateur ou son exécution par un interpréteur. Disposer du code source permet de comprendre, de corriger et de modifier un logiciel ; c'est pourquoi sa publication est la condition du [[Logiciel libre|logiciel libre]] et de l'[[Licences libres|open source]], alors qu'un logiciel propriétaire n'est souvent distribué que sous forme exécutable.
