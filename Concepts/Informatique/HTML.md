**Définition** (d'après [[2 - Histoire du design]]) : *HyperText Markup Language*, langage qui structure l'information d'une page Web : texte, titres, paragraphes, images, liens, ressources diverses. Son apport essentiel est le [[Lien hypertexte|lien hypertexte]], qui rend la navigation non linéaire.

Complément (hors du cours) : HTML est un langage de **balisage**, non de programmation : des balises encadrent les éléments et disent ce qu'ils sont, pas comment ils s'affichent.

```html
<h1>Histoire du Web</h1>
<p>Le Web est proposé au <a href="https://home.cern">CERN</a> en 1989.</p>
<img src="mosaic.png" alt="Capture de Mosaic">
```

La mise en forme relève des feuilles de style CSS (1996), l'interactivité de JavaScript (1995). Créé par Tim Berners-Lee vers 1990-1991, HTML est normalisé par le W3C (HTML5 en 2014), puis tenu à jour depuis 2019 par le WHATWG sous forme de norme évolutive (*HTML Living Standard*). La balise `<img>`, ajoutée en 1993 pour le navigateur Mosaic, a fait du Web un média graphique. Un balisage sémantique (titres hiérarchisés, texte alternatif des images) conditionne l'[[Accessibilité|accessibilité]] d'une page. [[Complément hors du cours|ⓘ]]
