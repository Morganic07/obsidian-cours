**Définition (complément, hors du cours)** : logiciel dont la licence garantit à chacun quatre libertés : l'utiliser pour tout usage, étudier son fonctionnement (ce qui suppose l'accès au [[Code source|code source]]), le redistribuer, et le modifier puis diffuser ses versions modifiées. Le mouvement est lancé par Richard Stallman avec le projet GNU (1983) et la Free Software Foundation (1985) ; sa licence GPL (1989) impose que les versions dérivées restent libres ([[Copyleft]]). L'expression concurrente « open source » ([[Licences libres]]), adoptée en 1998, insiste sur l'efficacité du développement ouvert plutôt que sur l'éthique. [[Linux]], Firefox ([[Mozilla]]) ou Apache en sont des exemples. [[Complément hors du cours|ⓘ]]

## Dans le cours

[[2 - Histoire du design]] : en 1993, le CERN rend librement disponibles le code source du navigateur, celui du serveur et les spécifications du Web, ce qui permet sa diffusion (le logiciel est placé dans le domaine public).

[[6 - design libre]] : enquête SHS de 4e année sur les articulations du design avec les logiciels libres et les communs numériques ; la restitution doit être publiée sous licence libre et réalisée autant que possible avec des outils libres.
