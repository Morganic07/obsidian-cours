**Définition (complément, hors du cours)** : ReFS (Resilient File System) est un [[Système de fichiers|système de fichiers]] de Microsoft, introduit avec Windows Server 2012 pour succéder à [[NTFS]] sur les serveurs de stockage. Il est conçu pour l'intégrité des données et les très grands volumes : sommes de contrôle sur les métadonnées (et en option sur les données), détection et correction automatique de la corruption avec les espaces de stockage redondants. Il ne sert pas de volume de démarrage de Windows et n'offre pas toutes les fonctions de NTFS.
