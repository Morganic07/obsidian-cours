**Définition (complément, hors du cours)** : valeur écrite telle quelle dans le code source : `10` (entier), `3.14` (`double`), `'a'` (caractère), `"rouge"` (chaîne), `true` (booléen). Des suffixes en précisent le type : `100U` (non signé), `3.5f` (`float`), `10L` (`long`). C'est une [[Expression (programmation)|expression]] dont la valeur est connue à la compilation.

## Dans le cours

[[4 - Cours complet]] cite les littéraux comme forme la plus simple d'expression, et conseille d'éviter les littéraux semés dans le code au profit de [[Constante (programmation)|constantes]] nommées (voir [[Nombre magique (programmation)]]). L'exercice 4 utilise des littéraux non signés `0U` et `100U`.
