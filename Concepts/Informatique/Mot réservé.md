Mots prédéfinis du langage C, qu'on ne peut pas réutiliser comme identifiants. Le cours les classe par catégorie :

- types : `char`, `int`, `float`, `void`… ;
- boucles : `do`, `for`, `while` ;
- sélections : `if`, `else`, `switch`, `case`, `default` ;
- ruptures de séquence : `break`, `continue`, `goto`, `return` ;
- classes d'allocation : `auto`, `extern`, `register`, `static` ;
- constructeurs : `enum`, `struct`, `typedef`, `union` ;
- divers : `sizeof`…

Règles de nommage associées : pas d'espace ni de `-`, pas de chiffre en première position.

Notion parente : [[Langage C]]. Voir aussi : [[Type primitif]].

## Dans le cours

[[4 - Cours complet]] (C++) rappelle que `int` est un mot réservé (mot-clé), qui ne peut pas nommer autre chose, et que les mots-clés sont interdits comme noms de variables et de fonctions.
