Langage développé par Guido van Rossum ; [[Langage interprété|interprété]], [[Typage dynamique|typé dynamiquement]], à indentation significative (AlgoID1).

Opérateurs arithmétiques (dont `//` et `**`), logiques (`and`, `or`, `not`) et relationnels ; entrées et sorties avec `input` et `print`.

La note de cours ajoute : afficher prend plus de temps que calculer ; `print(..., end="")` supprime le retour à la ligne ; `_` sert de variable de boucle inutilisée.

Voir aussi : [[Typage dynamique]], [[Langage interprété]], [[Fonction range (Python)]], [[Passage de paramètres]], [[Dataclass (Python)]].

## Erreurs du cours

- AlgoID1 ([[Raw/Year 1/Algo Maths/AlgoID1.pdf|AlgoID1.pdf]], diapositive 18) écrit `print i` dans l'exemple de boucle sur une chaîne ; il faut `print(i)` en Python 3 (`print i` est la syntaxe de Python 2), comme dans les autres exemples de la diapositive.
