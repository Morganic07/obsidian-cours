**Définition** (d'après [[4 - Cours complet]]) : programme qui traduit le [[Code source|code source]], lisible par un humain, en [[Code machine|code objet]] qu'une machine peut exécuter, après en avoir vérifié la syntaxe. Il est « pointilleux » et dénué de bon sens : ses messages d'[[Erreur de compilation|erreur]] sont à lire attentivement, car il a généralement raison.

## Dans le cours

[[4 - Cours complet]] présente la compilation comme la première étape de fabrication d'un programme C++ : source `.cpp` → compilateur (g++, voir [[GCC]]) → code objet `.o`, avant l'[[Édition de liens|édition de liens]]. Les compilateurs C++ courants sont GCC, Clang et MSVC (complément, hors du cours).

Voir aussi : [[Langage compilé]], [[Chaîne de compilation]], [[Langage interprété]].
