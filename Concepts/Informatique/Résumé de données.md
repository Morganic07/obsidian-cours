**Définition (complément, hors du cours)** : tâche descriptive de la fouille de données qui produit une description compacte d'un jeu de données ou d'un sous-groupe : indicateurs de [[Statistique descriptive|statistique descriptive]] (moyenne, dispersion, répartition), profils caractéristiques de groupes issus d'un [[Clustering|clustering]], tableaux agrégés. Elle sert à explorer les données avant de les modéliser et à communiquer les résultats.

## Dans le cours

Nommé dans le schéma des tâches du data mining de [[2 - association rules]] (*Summarization*), parmi les tâches descriptives, sans définition.

Notion parente : [[Fouille de données]]. Voir aussi : [[Apprentissage non supervisé]].
