**Définition** (d'après [[4 - Cours complet]]) : message qui précède le curseur sur la dernière ligne d'une console (en anglais *prompt*) ; il contient toujours le nom du répertoire courant. Dans la documentation, il est représenté par `$` devant les commandes.

Complément, hors du cours : sous Bash, son format est fixé par la variable `PS1` (par exemple `utilisateur@machine:~/C-C++/tp1$`) ; il se termine par `#` pour le [[Super-utilisateur root|super-utilisateur]]. À ne pas confondre avec le message d'invite d'un programme, qui demande une saisie à l'utilisateur.

## Dans le cours

[[4 - Cours complet]] le fait observer en changeant de répertoire avec `cd` (voir [[Shell et Bash]], [[Interface en ligne de commande]]).
