Langage pour spécifier un [[Algorithme]] sur papier avant de le programmer. Structure `PROGRAMME ... DEBUT ... FIN`, commentaires, `ECRIRE` et `LIRE` ; les variables sont déclarées avant le programme. Les examens d'informatique de 1re année sont écrits en pseudo-code.

Notion parente : [[Algorithme]]. Voir aussi : [[Affectation]], [[Structure conditionnelle]], [[Boucle (programmation)]], [[Type primitif]].

## Erreurs du cours

- AlgoID1 ([[Raw/Year 1/Algo Maths/AlgoID1.pdf|AlgoID1.pdf]]) écrit `rep : INTEGER` dans le programme complet ; il faut `rep : ENTIER`, le type de son pseudo-code.
- La syntaxe de la boucle écrit `FINTANQUE` ; il faut `FINTANTQUE`, comme dans les exemples suivants.
- La fonction est déclarée `calculeCarre`, mais appelée `calculCarre(12)` ; il faut le même nom aux deux endroits.
