Langage pour spécifier un [[Algorithme]] sur papier avant de le programmer. Structure `PROGRAMME ... DEBUT ... FIN`, commentaires, `ECRIRE` et `LIRE` ; les variables sont déclarées avant le programme, avec les types du pseudo-code (`rep : ENTIER`) ; une boucle `TANTQUE` se ferme par `FINTANTQUE`, et une fonction s'appelle par le nom sous lequel elle est déclarée (`calculeCarre(12)`). [[Erreurs du cours#^e-pseudo-code|✎]] Les examens d'informatique de 1re année sont écrits en pseudo-code.

Notion parente : [[Algorithme]]. Voir aussi : [[Affectation]], [[Structure conditionnelle]], [[Boucle (programmation)]], [[Type primitif]].
