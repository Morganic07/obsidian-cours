En Bash :

- **ET** : `[ c ] && [ c ]`, `[ c -a c ]` ou `[[ c && c ]]` ;
- **OU** : `[ c ] || [ c ]`, `[ c -o c ]` ou `[[ c || c ]]`.

En [[AWK]] aussi, `||` est le OU et `&&` le ET.

Notion parente : [[Structure conditionnelle]]. Voir aussi : [[Opérateur de comparaison]].
