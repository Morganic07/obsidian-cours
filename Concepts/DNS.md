La conversion des noms d'hôte en adresses IP s'appelle la résolution d'adresse ; elle est faite par le DNS. Quand on tape un nom dans un navigateur, les serveurs DNS le résolvent en adresse IP.

Voir aussi : [[Nom d'hôte]], [[Fichier hosts]].

- Écart entre sources : le sujet du TP3 ([[raw/Year 2/Operating System/DM/TP3/TP3-Commands  (2).pdf|TP3-Commands  (2)]]) développe DNS en « Domain Name Server », le [[cours TP1]] en « Domain Name System » (forme usuelle).
