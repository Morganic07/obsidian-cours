Propos d'une étudiante interrogée lors de l'enquête SHS sur l'open source : le readme est « un fondamental ». Il n'est pas pour soi mais pour les autres : il présente le projet, ses prérequis et l'arborescence des fichiers, et elle le nettoie avant de rendre un dépôt réutilisable. On peut aussi y indiquer les conditions d'usage commercial.

Voir aussi : [[Git]], [[Licences libres]].

## À vérifier

- Propos d'une interviewée.
