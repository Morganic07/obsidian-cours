- To see which directories and data are loaded, type:
```
search()
```

- To see which objects are stored, type:
```
ls()
```

- To include a dataset in the search path for analysis, type:
```
attach(NameOfTheDataset, expression)
```

- To detach a dataset from the searchpath after analysis, type:
```
detach(NameOfTheDataset)
```
