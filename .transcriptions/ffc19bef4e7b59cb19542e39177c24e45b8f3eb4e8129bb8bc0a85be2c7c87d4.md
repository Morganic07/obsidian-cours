Figure : Deux piles d'appels récursifs de la fonction f, de f(0) en haut à f(5) en bas. À gauche, l'empilement (flèche bleue vers le haut) montre les appels. À droite, le dépilement (flèche bleue vers le bas) montre les valeurs renvoyées, en rouge.

**Empilement** (de bas en haut) :

- **f(5)** : → 5 + f(4) ; *Au programme*
- **f(4)** : → 4 + f(3) ; à f(5)
- **f(3)** : → 3 + f(2) ; à f(4)
- **f(2)** : → 2 + f(1) ; à f(3)
- **f(1)** : → 1 + f(0) ; à f(2)
- **f(0)** : → 0 ; à f(1)

**Dépilement** (de haut en bas) :

- **f(0)** : → **0** ; à f(1)
- **f(1)** : → **1** ; à f(2)
- **f(2)** : → **3** ; à f(3)
- **f(3)** : → **6** ; à f(4)
- **f(4)** : → **10** ; à f(5)
- **f(5)** : → **15** ; Au programme
