mkdir instead of touch to create arborescent files :

```
mkdir -p semester/{first/{os,uc},second/{cn,db,ns,cs},third/{iot,sp,dc}}
```

```
momo@penguin:~$ mkdir -p semester/{first/{os,uc},second/{cn,db,ns,cs},third/{iot,sp,dc}}
```

```
momo@penguin:~$ tree semester/
semester/
├── first
│   ├── os
│   └── uc
├── second
│   ├── cn
│   ├── cs
│   ├── db
│   └── ns
└── third
    ├── dc
    ├── iot
    └── sp

13 directories, 0 files
```
