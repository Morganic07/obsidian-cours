- Let $E = \{e_i\}$ be a training set:
- each example is defined by a vector of attributes, and its class value $c_i$.
- To each attribute $j$ is associated a test $T_j$ :

$$T_j : E \rightarrow V_j = \{V_{ji}\}$$

- Example : Test of the attribute OUTLOOK is given by:
  $T_1 : E \rightarrow \{sunny, overcast, rainy\}$.
