PC2 (17%)

SS(PC1 distances) = Eigenvalue for PC1
SS(PC2 distances) = Eigenvalue for PC2

Convert them into variation around the origin:

→ SS(PC1 distances) / $(n-1)$
→ SS(PC2 distances) / $(n-1)$
$n$: sample size

PC1 (83%)

Points : S1, S2, S3, S4, S5, S6

Say one finds **var PC1=15** and **var PC2=3**.
→ total PCs var = 15+3=18
→ **PC1** accounts for 15/18=83% of the total PCs var
→ **PC2** accounts for 3/18=17% of the total PCs var

Encadré :

$S^2 = \dfrac{\sum (x_i - \bar{x})^2}{n-1}$

- $S^2$ = sample variance
- $x_i$ = the value of the one observation
- $\bar{x}$ = the mean value of all observations
- $n$ = the number of observations
