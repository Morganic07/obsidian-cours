**Loading plot (→ correlation matrix)**

$A = \sigma_1 u_1 v_1^T + \dots + \sigma_r u_r v_r^T$

The **loading plot** graphs the coefficients of each variable for the first component versus the coefficients for the second component.

**Interpretation**

- Use the **loading plot** to **identify which variables have the largest effect on each component**.
- Loadings can range from $-1$ to $+1$.
- Loadings close to **$-1$ or $+1$** indicate that the variable **strongly influences** the component.
- Loadings close to **0** indicate that the variable has a **weak influence** on the component.
