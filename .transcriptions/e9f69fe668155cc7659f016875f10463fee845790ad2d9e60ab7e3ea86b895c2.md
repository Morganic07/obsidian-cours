STATISTICS FORMULAS

$\overline{X} = \dfrac{\sum_{i=1}^{n} X_i}{n}$

$IQR = Q_3 - Q_1$

$CV = \dfrac{s}{\overline{X}} \times 100\%$

$\mu = \dfrac{\sum_{i=1}^{n} X_i}{N}$

$s = \sqrt{\dfrac{\sum_{i=1}^{n}(X_i - \overline{X})^2}{n-1}}$

$s^2 = \dfrac{\sum_{i=1}^{n}(X_i - \overline{X})^2}{n-1}$

$\sigma = \sqrt{\dfrac{\sum_{i=1}^{n}(X_i - \mu)^2}{N}}$

$\sigma^2 = \dfrac{\sum (X_i - \mu)^2}{N}$

$Z = \dfrac{X - \overline{X}}{s}$

$Z = \dfrac{X - \mu}{\sigma}$

$Z = \dfrac{\overline{X} - \mu}{\frac{\sigma}{\sqrt{n}}}$

$Z = \dfrac{\overline{X} - \mu}{\frac{s}{\sqrt{n}}}$

$P(A \text{ or } B) = P(A \cup B)$ $\quad = P(A) + P(B)$ if A and B are mutually exclusive
$P(A \text{ or } B) = P(A \cup B)$ $\quad = P(A) + P(B) - P(A \text{ and } B)$
$P(A \text{ and } B) = P(A \cap B)$ $\quad = P(A)\,P(B)$ if A and B are independent
$P(A \text{ and } B) = P(A \cap B)$ $\quad = P(A|B)\,P(B)$ if A and B are not independent
$\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad = P(B|A)\,P(A)$

$P(A|B) = P(A \text{ and } B)\,/\,P(B)$
$P(B|A) = P(B \text{ and } A)\,/\,P(A)$ note: $P(A \text{ and } B) = P(B \text{ and } A)$

$nPr = n!\,/(n-r)!$

$nCr = n!\,/\,r!\,(n-r)!$

$P(x) = nCx\,P^x(1-P)^{n-x}$

mean of binomial $(\mu) = nP$

Variance of Binomial $(\sigma^2) = nP(1-P)$

$r = \dfrac{n\sum XY - \sum X \sum Y}{\sqrt{(n\sum X^2 - (\sum X)^2)(n\sum Y^2 - (\sum Y)^2)}}$

$t_{n-2} = \dfrac{r\sqrt{n-2}}{\sqrt{1-r^2}}$

$b = \dfrac{n\sum XY - \sum X \sum Y}{n\sum X^2 - (\sum X)^2}$

$a = \overline{Y} - b\overline{X}$

$\hat{Y} = a + bX$

Notation: a is the same as $b_0$ and b is the same as $b_1$
