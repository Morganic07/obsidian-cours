**TABLE 4 — Projections** (transformation, image du carré unité, matrice standard)

- Projection onto the $x_1$-axis (projection sur l'axe $Ox_1$) : le carré unité est écrasé sur le segment de $\begin{bmatrix} 0 \\ 0 \end{bmatrix}$ à $\begin{bmatrix} 1 \\ 0 \end{bmatrix}$. Matrice : $\begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}$
- Projection onto the $x_2$-axis (projection sur l'axe $Ox_2$) : le carré unité est écrasé sur le segment de $\begin{bmatrix} 0 \\ 0 \end{bmatrix}$ à $\begin{bmatrix} 0 \\ 1 \end{bmatrix}$. Matrice : $\begin{bmatrix} 0 & 0 \\ 0 & 1 \end{bmatrix}$
