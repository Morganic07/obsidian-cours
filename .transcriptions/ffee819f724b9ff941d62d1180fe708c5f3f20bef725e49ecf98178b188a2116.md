Figure : Organigramme de l'installation d'un système d'exploitation. Depuis « Operating System Installation », la branche de gauche (PC/Laptop) mène de l'image iso à la clé USB bootable, puis au démarrage et à l'installation. La branche de droite (Virtual Machine) passe par un choix selon l'OS hôte (Windows : Virtual Box, Ubuntu : KVM), puis par la création de la machine virtuelle, l'obtention de l'image iso et l'installation.

**Operating System Installation**

**PC/Laptop**
1. Obtain iso image Windows / Ubuntu
2. Make a bootable USB using Rufus — Download Rufus to make bootable USB
3. Boot your PC/laptop from bootable USB
4. Start installing windows or Ubuntu

**Virtual Machine**
- Host OS ?
  - Windows : Install Virtual Box
  - Ubuntu : Install KVM
- Create a virtual machine
- Obtain iso image Windows / Ubuntu
- Start installing windows or Ubuntu on virtual machine

**NOTE:** Bootable USB is not required if installing OS on the virtual machine
