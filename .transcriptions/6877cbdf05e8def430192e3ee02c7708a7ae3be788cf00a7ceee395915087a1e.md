$z_\alpha$ is such that

$P\{Z > z_\alpha\} = \alpha$

when $Z$ is a standard normal random variable. But this implies that for any $\alpha$

$P\{-z_{\alpha/2} < Z < z_{\alpha/2}\} = 1 - \alpha$

As a result, we see that

$P\left\{-z_{\alpha/2} < \sqrt{n}\,\dfrac{(\overline{X} - \mu)}{\sigma} < z_{\alpha/2}\right\} = 1 - \alpha$
