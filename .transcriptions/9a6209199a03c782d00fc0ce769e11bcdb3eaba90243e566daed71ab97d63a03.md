# Classifier Validation: illustration

Figure : Schéma du processus de validation d'un classifieur. La base de données (Database) est séparée en données d'entraînement (Training Data) et données de test (Testing Data). Les données d'entraînement alimentent la construction du modèle (Model Construction), qui produit le modèle construit (Constructed Model). Les données de test sont envoyées vers ce modèle pour évaluer sa précision (Acceptable Accuracy ?). Si la réponse est « Yes », le modèle est appliqué à des valeurs ou classes inconnues (Unknown Value or Class), ce qui donne une prédiction (Prediction), puis la valeur prédite (Predicted Value).

Textes du schéma : Database, Training Data, Testing Data, Model Construction, Constructed Model, Acceptable Accuracy, Yes, Unknown Value or Class, Prediction, Predicted Value.
