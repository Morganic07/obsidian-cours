- On utilise le mot-clé length pour obtenir la taille d'un tableaux

▶ Exemples :

```java
int valeurs[] = { 5, 2, 4, 8, 9};
Systemt.out.println(valeurs.length);          → 4
int matrice [ ][ ] = { {1, 2, 3}, {4, 5, 6},};
System.out.println(matrice.length);           → 2
System.out.println(matrice[01.length);        → 3
```

À vérifier : la dernière ligne est coupée en bas de l'image, et `matrice[01.length` est probablement `matrice[0].length`. `Systemt.out` à la 2e ligne de code semble être une faute de frappe de la source pour `System.out`. J'ai laissé les deux tels quels.
