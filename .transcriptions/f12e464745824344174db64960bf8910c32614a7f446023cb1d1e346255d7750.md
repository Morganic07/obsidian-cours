# Classifier Validation -1

- The classifier error $Er$ is the probability that the classifier does not predict correctly the target value of a given data.
- Success ratio is $1 - Er$.
- The training error is measured on the training set (used to construct the classifier).
- To estimate the classifier quality we need:
  - A training set $X_{train}$;
  - A test set $X_{test}$ in order to estimante the classification error, the target value is given in the test set for each example.

À vérifier : « estimante » semble être une faute de frappe dans l'original (recopié tel quel).
