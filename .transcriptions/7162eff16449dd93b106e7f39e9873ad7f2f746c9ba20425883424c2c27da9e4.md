- Les noms de variables :
    - Doivent commencer avec une lettre, le symbole `_`, ou le symbole `$`.
        - ✓ `compteur` ✗ `3distance`
    - Ne peuvent pas être des mots-clés.
        - ✗ `double`
    - Peuvent être une séquence de lettres, de nombres, des symboles `_` ou `$` qui suivent les 2 règles antérieures.
        - ✓ `inc_delta` ✓ `nombre3`
