Combinaison de Plusieurs modèles

Figure : Schéma d'un ensemble de classifieurs. Les « Training Examples » alimentent trois échantillons (« Test Sample 1 », « Test Sample 2 », « Test Sample 3 »). Chacun passe par un « Learning Algorithm » puis donne un classifieur (« Classifier 1 », « Classifier 2 », « Classifier 3 »). Les trois classifieurs sont réunis dans « Combined Classifiers », qui reçoit aussi de « New Data » et produit une « Prediction ».

À vérifier : les échantillons sont étiquetés « Test Sample » alors que, d'après le schéma, il s'agit d'échantillons d'apprentissage.
