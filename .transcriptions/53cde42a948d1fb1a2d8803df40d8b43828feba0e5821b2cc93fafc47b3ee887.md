La portée d'une variable est la région dans le code où la variable peut être utilisée pour une assignation (écriture) ou pour accéder à sa valeur(lecture).

Dans une portée, tous les noms des variables doivent être uniques.

Deux variables ne peuvent pas avoir le même nom.

Les régions dans le code sont généralement déterminées par des paires d'accolades { … }
