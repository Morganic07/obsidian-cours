**Theorem**

Let $(a, b) \in \mathbb{R}^2$. We have

1. If $a < b$:
   1. $x^a \underset{+\infty}{=} o(x^b)$.
   2. $x^b \underset{0^+}{=} o(x^a)$.
2. $\forall a > 0, \forall b > 0$:
   1. $\lim_{x \to +\infty} \frac{x^b}{e^{ax}} = 0 \iff x^b \underset{+\infty}{=} o(e^{xa})$.
   2. $\lim_{x \to +\infty} \frac{(\ln x)^b}{x^a} = 0 \iff (\ln x)^b \underset{+\infty}{=} o(x^a)$.
   3. $\lim_{x \to -\infty} |x|^b e^{ax} = 0 \iff e^{xa} \underset{-\infty}{=} o\left(\frac{1}{|x|^b}\right)$.
   4. $\lim_{x \to 0^+} x^a |\ln x|^b = 0 \iff |\ln x|^b \underset{0^+}{=} o\left(\frac{1}{x^a}\right)$.
