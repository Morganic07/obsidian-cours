**1.6 Special Escaping Characters:**

Treat certain characters as literals (e.g. `\`, `` ` ` ``)

- `\` — Escapes the next character treating it as a literal.

```
rm file\ name.txt          # Deletes a file named "file name.txt"
rm file\ file2.txt         # Deletes a file named “file2.txt”
```

- ` `` ` (Backticks) — Executes the enclosed command and substitutes its output.

```
echo `pwd`                 # Prints the current directory path
```

À vérifier : dans la deuxième ligne de code, le commentaire indique « file2.txt » alors que la commande échappe « file\ file2.txt » (nom avec espace attendu), et les guillemets sont typographiques (“ ”) au lieu de droits.
