# STATISTICS FORMULAS

$Z = \dfrac{\overline{X} - \mu_H}{\dfrac{\sigma}{\sqrt{n}}}$

$\overline{X} \pm Z_\alpha \dfrac{\sigma}{\sqrt{n}}$

$t_{n-1} = \dfrac{\overline{X} - \mu_H}{\dfrac{s}{\sqrt{n}}}$

$\overline{X} \pm t_{\alpha,\,n-1} \dfrac{s}{\sqrt{n}}$

$Z \approx \dfrac{P_s - P}{\sqrt{\dfrac{P(1-P)}{n}}}$

$P_s \pm Z_\alpha \sqrt{\dfrac{P_s(1-P_s)}{n}}$

$Z = \dfrac{\overline{X}_1 - \overline{X}_2}{\sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}}$

$(\overline{X}_1 - \overline{X}_2) \pm Z_\alpha \sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}$

$Z = \dfrac{\overline{X}_1 - \overline{X}_2}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}$

$(\overline{X}_1 - \overline{X}_2) \pm Z_\alpha \sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}$

$t_{n_1+n_2-2} = \dfrac{\overline{X}_1 - \overline{X}_2}{\sqrt{S^2_{pooled}\left(\dfrac{1}{n_1} + \dfrac{1}{n_2}\right)}}$

$S^2_{pooled} = \dfrac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1 + n_2 - 2}$

$Z \approx \dfrac{P_{s1} - P_{s2}}{\sqrt{\overline{P}(1-\overline{P})\left(\dfrac{1}{n_1} + \dfrac{1}{n_2}\right)}}$

$\overline{P} = \dfrac{x_1 + x_2}{n_1 + n_2}$

$n = \dfrac{Z^2 \sigma^2}{e^2}$

$n = \dfrac{Z^2 P(1-P)}{e^2}$

$\chi^2 = \dfrac{(f_o - f_e)^2}{f_e}$

$f_e = \dfrac{\text{row total} * \text{column total}}{n}$
