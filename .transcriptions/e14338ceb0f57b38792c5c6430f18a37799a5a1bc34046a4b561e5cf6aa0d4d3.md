**Example-continued**: consider the set {a,b,c,d,e} consisting of five elements.

We have 3!=6 permutations of the elements a,b,c. If we don't consider the order, all these permutations are equivalent to the single combination {a,b,c}

For each combination of size 3, there are 3! Permutations that are different orderings of the same set, so we can group

$_5P_3 = 60 = $ (number of combinations of size 3)$\cdot 3!$

That is: (number of combinations of size 3)$=\dfrac{_5P_3}{3!}=10$

This can be done for combinations of any size $k$.
