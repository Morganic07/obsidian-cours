# Definitions & Notations

- - X : Examples set $|X| = N$ (cardinality de X).
  - K : Clusters number (an algorithm parameter).
- Given an examples set X, each of them characterized by P attributes: the centroid of X named g, is a *synthetical example* described by : $g = \{\bar{a}_1 \dots \bar{a}_i\}$ where $\bar{a}_i$ is the average of all $a_i$ values in X.
- *Aim* : Find K cluster: each cluster will be represented by its centroid $g_i$.
  - Non hierarchical approaches (k-means).
  - Hierarchical approaches.

À vérifier : la première puce du diaporama est vide, et les deux sous-puces X et K sont imbriquées sous elle.
