i) For any event $A \subset S$, $P(A) = 1 - P(A^c)$

ii) For the empty set $\emptyset$ we have $P(\emptyset) = 0$

iii) For all $A \subset S$, $P(A) \leq 1$

iv) For $A, B \subset S$, $P(A \cup B) = P(A) + P(B) - P(A \cap B)$

v) For $A, B \subset S$, $P(A \cup B) \leq P(A) + P(B)$

vi) For any finite collection of disjoint sets $A_1, A_2, \dots, A_n$, we have

$$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i) \quad \textit{(finite additivity)}$$

vii) For any finite collection of sets $A_1, A_2, \dots, A_n$,

$$P\left(\bigcup_{i=1}^{n} A_i\right) \leq \sum_{i=1}^{n} P(A_i) \quad \textit{(finite sub-additivity)}$$
