# Linear combinations of independent rvs

**THEOREM**

Let the rvs $X_1, X_2, \ldots, X_n$ have mean values $\mu_1, \ldots, \mu_n$ and standard deviations $\sigma_1, \ldots, \sigma_n$, respectively.

2. If $X_1, \ldots, X_n$ are independent,

$$\text{Var}(a_1X_1 + \cdots + a_nX_n + b) = a_1^2\,\text{Var}(X_1) + \cdots + a_n^2\,\text{Var}(X_n)$$

$$= a_1^2\sigma_1^2 + \cdots + a_n^2\sigma_n^2$$

and

$$\text{SD}(a_1X_1 + \cdots + a_nX_n + b) = \sqrt{a_1^2\sigma_1^2 + \cdots + a_n^2\sigma_n^2}$$
