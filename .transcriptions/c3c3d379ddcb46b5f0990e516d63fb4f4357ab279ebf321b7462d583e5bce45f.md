# Classifier Validation-4

- Cross Validation Technics:
  - Cut up the data set to $n$ disjoint subsets of the same size.
  - Each target value have to appear in the $n$ subsets.
    - Let A,B,C are 3 subsets:
    - The classifier build from $A \cup B$ is named $CL_{A\cup B}$,
    - The test error computed on $C$ is named $Er_C$.
    - Three tests are done: $(CL_{A\cup B}, Er_C)$, $(CL_{C\cup A}, Er_B)$, $(CL_{C\cup B}, Er_A)$.
    - The global error rate is given by par $Er = \frac{Er_A + Er_B + Er_C}{3}$
