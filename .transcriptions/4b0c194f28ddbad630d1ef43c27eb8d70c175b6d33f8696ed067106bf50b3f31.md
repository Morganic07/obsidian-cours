# Calcul de l'aire d'un cercle

```java
public class Aire {
    public static void main(String[] args) {
        double rayon = Double.parseDouble(args[0]);
        double pi = 3.1416;
        double aire = pi * rayon * rayon;
        System.out.print(" Aire d'un cercle avec rayon " + rayon);
        System.out.println(" est " + aire);
    }
}
```

`args[0]` contient la valeur du premier paramètre

`args[i`^ième^`]` contient la valeur du i^ème^ paramètre

`Double.parseDouble` fait la conversion d'un String à une valeur double

À vérifier : le deuxième commentaire est partiellement souligné par le correcteur orthographique et se lit « args[i^ème^] contient la valeur du i^ème^ paramètre ». La transcription de « args[i^ème^] » est incertaine.
