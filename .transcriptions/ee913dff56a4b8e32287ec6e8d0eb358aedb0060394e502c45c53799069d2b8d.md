BFS(graph, start_node):

1. Create a queue and enqueue the start_node.
2. Mark *start_node* as visited.
2. While the queue is not empty:
   - Dequeue a node $v$ from the queue.
   - *print*($v$).
   - For each *child* of $v$:
     - If *child* has not been visited:
       - Mark *child* as visited.
       - Enqueue *child*.

À vérifier : la numérotation répète « 2. » pour la deuxième et la troisième étape, comme dans l'image.
