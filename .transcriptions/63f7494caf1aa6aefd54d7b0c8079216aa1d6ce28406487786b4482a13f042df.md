# Clustering & Partitioning

- Given a data set of unlabeled examples X, Find a partition of X into k clusters verifying the following proprieties:
  1. Data belonging to one cluster $G_i$, ($i \in 1..k$) are similar.
  2. *2 different examples* belonging to *different clusters* are not similar.
- Example: *E-commerce web sites's Log analysis: user profile detection*.
