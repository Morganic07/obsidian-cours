# Random Forest - Algorithme

- $z = \{(x_1, y_1)..(x_n, y_n)\}$ échantillon d'apprentissage, $x_i$ décrit par $p$ variables explicatives
- Pour $t = 1..K$ (K représente le nombre d'arbres formés dans la forêt)
  - Tirer un échantillon aléatoire $z_t$ avec remise parmi z.
  - Estimer un arbre sur $z_t$ avec randomisation des variables :
  - Pour la construction de chaque nœud de chaque arbre, on tire uniformément $q$ variables parmi $p$ pour former la décision associée au nœud
- En fin d'algorithme, on possède $K$ arbres que l'on moyenne ou qu'on fait voter pour la régression ou la classification
