1) Open the `sudoers` file:

```
sudo visudo
```

2) Add or modify the `timestamp_timeout` value. For example, to set a timeout of 15 minutes (meaning no password prompt for 30 minutes after the first successful sudo command):

```
Defaults timestamp_timeout=15
```

À vérifier : le texte indique un délai de 15 minutes, mais l'explication entre parenthèses parle de 30 minutes. Cette incohérence figure dans l'image d'origine.
