- $(\mathbf{X}^T\mathbf{X})_{ij}$ → similarity of variance (or change) of the i-th feature and j-th feature.
- This value gets larger as the # of samples ($n$) increases
- For this reason, we solve this problem by dividing by $n$:

$$\Sigma = cov(X) \equiv \frac{X^T X}{n}$$ If the whole population is considered

$$cov(X) \equiv \frac{X^T X}{n-1}$$ If we work with samples

À vérifier : dans la dernière formule, le « −1 » du dénominateur est écrit en rouge dans l'image.
