CART algorithm -Gini Index

$$IG(No) = 1 - \sum_{1}^{NC} p_i^2 \qquad (5)$$

- $No$: A node that represents a subset of the data
- $NC$: Number of classes
- $p_i$: Frequency of class $i$ in the subset associated to the node $No$.
- More the Gini index is small, more the node is pure.
- Splitting one node to two nodes: we search to maximise the purity gain
- Search discrimination variable ; maximising:

$$IG(beforeSplit.) - [W_1 * IG(child1) + W_2 * IG(child2)]$$

$W_i$ is the ratio of examples represented by child $i$.
