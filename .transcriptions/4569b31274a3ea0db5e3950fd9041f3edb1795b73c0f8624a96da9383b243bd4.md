**Définition**

Un argument est une suite de proposition $p_1, \ldots, p_k$ appelées prémisses se terminant par une proposition $q$ appelée conclusion. On note $p_1, \ldots, p_k \vdash q$. Un argument est valide si dès que les prémisses sont vraies, la conclusion est vraie. Un argument qui n'est pas valide est dit fallacieux.

**Exemple**

$p \wedge q \vdash p$ est un argument valide et $q, p \Rightarrow q \vdash p$ est un fallacieux.
