Methods for choosing the right test.

- If the series has the form $\sum_{n\geq 1} \frac{1}{n^p}$, then it is a *p*-series.
- If the series is of the form $\sum_{n\in\mathbb{N}} ar^n$, then it is a geometric series.
- If the series has a form similar to a *p*-series or a geometric series, then the comparison test, the limit comparison test or asymptotically equivalence should be used. In particular, if $a_n$ is a rational function or an algebraic function, then the series should be compare with a *p*-series. Note that the comparison tests apply only for series with positive terms. If the series has negative terms, then the comparison tests apply with $\sum_{N\in\mathbb{N}} |a_n|$ to test absolute convergence.
- If $\lim_{n\to+\infty} a_n \neq 0$, then the test for divergence should be used.
