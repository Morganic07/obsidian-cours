# K-Means Method

- Definition:
  - The inertia of a data set X containing N examples: $I = \frac{1}{N}\sum_{i=1}^{N} d^2(x_i, g)$ where g is the centroid of X. and d is a distance function :

    | | |
    |---|---|
    | Euclidian | $\sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}$ |
    | Manhatan | $\sum_{i=1}^{n} \lvert x_i - y_i \rvert$ |
    | Hamming | |
    | ... | |

  - Let $I_1, .., I_n$ inertias of clusters (groups) $g_1 ... g_k$ *the intra-cluster inertia*: $I_w = \sum_{i=1}^{k} I_k$
  - Let $I_1 ... I_k$ inertias of clusters (groups) $g_1 ... g_k$ *the inter-cluster inertia* : $I_B = \sum_{i=1}^{k} w_i d^2(g_i, g)$ with $w_i = \frac{|g_i|}{N}$
  - $I = I_W + I_B$
  - *Aim* : get dense clusters (*groups*), well separated if possible: *Minimise $I_w$*.

À vérifier : dans la formule de $I_w$, l'indice de la somme est $i$ mais le terme est écrit $I_k$ (tel qu'il apparaît sur l'image). Les inerties sont aussi notées $I_1, .., I_n$ dans une puce et $I_1 ... I_k$ dans l'autre.
