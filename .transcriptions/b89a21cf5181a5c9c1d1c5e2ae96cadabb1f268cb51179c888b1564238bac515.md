# Classifier Validation-2

- Quality classification measures: *for each target value*:
  - **TP/TN:** True positive/negative frequency: positive/negative examples' number that have a positive/negative target value.
  - **FP/FN:** The negative/positive examples' number whose predicted target values are positive/negative.

- Confusion Matrix

|        | + Pred | - Pred |
|--------|--------|--------|
| Real + | TP     | FN     |
| Real - | FP     | TN     |
