**Definition**

Let $I$ be a symmetrical interval about the origin and $f$ be a function defined on $I$. We say that $f$ is an even function if $\forall x \in I,\ f(-x) = f(x)$.

**Proposition**

Let $f$ be a $2\pi$-periodic, piece-wise continuous and even function defined on $\mathbb{R}$. Then we have

$$a_0 = \frac{1}{\pi}\int_0^{\pi} f(x)\,dx, \quad \forall n \geq 1,\ a_n = \frac{2}{\pi}\int_0^{\pi} f(x)\cos nx\,dx,\ b_n = 0$$

Therefore

$$FS(f)(x) = a_0 + \sum_{n=1}^{+\infty} a_n \cos nx$$
