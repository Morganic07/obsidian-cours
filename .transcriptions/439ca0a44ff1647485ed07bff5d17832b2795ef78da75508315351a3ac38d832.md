Figure : Schéma en couches des composants d'un système informatique. En haut, l'« user » communique par une flèche bidirectionnelle avec les « application programs » (compilers, web browsers, development kits, etc.). Ces programmes communiquent par trois flèches bidirectionnelles avec l'« operating system », qui communique à son tour par trois flèches bidirectionnelles avec le « computer hardware » (CPU, memory, I/O devices, etc.).

Texte du schéma :

- user
- application programs (compilers, web browsers, development kits, etc.)
- operating system
- computer hardware (CPU, memory, I/O devices, etc.)
