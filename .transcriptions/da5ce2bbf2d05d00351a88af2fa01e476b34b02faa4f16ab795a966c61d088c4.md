- **Tri de sélection non récursif**

Si l'on s'intéresse qu'au nombre des instructions colorées, la complexité pour le pire des cas du tri de sélection est calculée de la manière suivante :

```
def triSelection(t) :
    n = len(t)
    for i in range(n - 1) :
        indMini = i
        for j in range(i + 1, n) :
            if t[j] < t[indMini] :
                indMini = j
        if i! = indMini :
            x = t[i]
            t[i] = t[indMini]
            t[indMini] = x
```

Cette couleur n'est pas reproduite dans le bloc de code. Le texte `i! = indMini` est recopié tel qu'il apparaît.
