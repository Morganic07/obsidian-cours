  - IF OUTLOOK= sunny& HUMI=strong THEN CLASS=N
  - IF OUTLOOK= sunny & HUMI=normal THEN CLASS=P
  - IF OUTLOOK= overcast THEN CLASSE=P
  - IF OUTLOOK= rainy & WIND=yes THEN CLASS=N
  - IF OUTLOOK= rainy & WIND=no THEN CLASS=P
