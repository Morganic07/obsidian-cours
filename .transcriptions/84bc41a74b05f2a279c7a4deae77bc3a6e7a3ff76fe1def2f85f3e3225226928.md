**Equation of the line** through $\mathbf{p}$ parallel to $\mathbf{v}$ : $\mathbf{x} = \mathbf{p} + t\mathbf{v}$ ($t$ in $\mathbb{R}$)

*The solution set of $A\mathbf{x} = \mathbf{b}$ is a line through $\mathbf{p}$ parallel to the solution set of $A\mathbf{x} = \mathbf{0}$.*

Figure de gauche : la droite $A\mathbf{x} = \mathbf{0}$ passe par l'origine, $\mathbf{v}$ et $t\mathbf{v}$ ; la droite parallèle $A\mathbf{x} = \mathbf{b}$ passe par $\mathbf{p}$ et $\mathbf{p} + t\mathbf{v}$.

Parallel solution sets of $A\mathbf{x} = \mathbf{b}$ and $A\mathbf{x} = \mathbf{0}$.

Figure de droite : dans $(x_1, x_2, x_3)$, le plan $A\mathbf{x} = \mathbf{0}$ passe par l'origine ; le plan parallèle $A\mathbf{x} = \mathbf{b}$ s'en déduit par le vecteur $\mathbf{p}$.
