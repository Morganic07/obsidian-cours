1.1 **Pattern matching or Wildcards**

Used to match specific file names or text patterns (e.g. `*`, `?`, `[]`)

- `*` — The asterisk or star character matches zero or more characters.

```
ls *.txt                # list all .txt files in the directory
```

- `?` — Matches exactly one character

```
ls file?.txt            # matches files like file1.txt, file4.txt
```

- `[]` — Matches any one character within the brackets

```
ls file[123].txt        # matches file1.txt, file2.txt, file3.txt
```

- `{}` — Expands to generate multiple options

```
touch file{1,2,3}.txt # creates file1.txt, file2.txt, file3.txt
```
