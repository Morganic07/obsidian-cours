| Command | Purpose |
|---|---|
| `router rip` | Enters **RIP routing protocol configuration mode** so that RIP settings can be configured on the router. |
| `version 2` | Enables **RIPv2**, which supports classless routing, VLSM, authentication, and multicast updates (sent to 224.0.0.9). |
| `no auto-summary` | Disables **automatic classful route summarization**. This allows RIP to advertise **subnet-level routes** rather than summarizing them to their classful boundary. Essential when using non-contiguous networks or VLSM. |
| `network <network address>` | Enables RIP updates on interfaces whose addresses fall within the specified network. It also tells RIP to **advertise that network** to other routers. |
| `default information-originate` | Causes the router to **advertise a default route (0.0.0.0/0)** into RIP, *if the router has a default route in its routing table*. It essentially injects a default route into RIP so downstream routers can use it. |
