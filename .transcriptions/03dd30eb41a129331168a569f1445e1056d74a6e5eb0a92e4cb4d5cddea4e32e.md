• IP (Internet Protocol) is a numerical label assigned to a device participating in a computer network that uses IPv4 protocol. It serves two primary purposes:
  - **Device identification:** Uniquely identifies a device on a network.
  - **Location Addressing:** Specifies the device location within the network to facilitate communication.
