Finding a minimum spanning tree (1)

A first solution might be an exhaustive search, that is:

- List all spanning trees;
- Calculate the value of each one;
- Choose one among those with the lowest value.

This solution has exponential complexity; it is therefore impractical as it is too costly.

Finding a minimum spanning tree (2)

Another solution is to apply a "greedy" algorithm: Kruskal's algorithm.

1. Initialize the spanning graph with no edges.
2. Let $e$ be the untested edge with the lowest weight: if $e$ does not form a cycle, add it to the current spanning graph.
