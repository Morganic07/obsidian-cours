One potential difficulty is that occasionally an observation falls on a class boundary and therefore does not lie in exactly one interval, for example, 29.0.

We will use the convention that any observation falling on a class boundary will be included in the class to the right of the observation. Thus 29.0 would go in the 29.0–29.5 class rather than the 28.5–29.0 class

Generally, the larger the number of observations in a data set, the more classes should be used. A reasonable rule is

$$\text{number of classes} \approx \sqrt{\text{number of observations}}$$
