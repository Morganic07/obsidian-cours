A vector equation

$x_1\mathbf{a}_1 + x_2\mathbf{a}_2 + \cdots + x_n\mathbf{a}_n = \mathbf{b}$

has the same solution set as the linear system whose augmented matrix is

$[\mathbf{a}_1 \ \mathbf{a}_2 \ \cdots \ \mathbf{a}_n \ \mathbf{b}] \qquad (5)$

In particular, $\mathbf{b}$ can be generated by a linear combination of $\mathbf{a}_1, \dots, \mathbf{a}_n$ if and only if there exists a solution to the linear system corresponding to the matrix (5).
