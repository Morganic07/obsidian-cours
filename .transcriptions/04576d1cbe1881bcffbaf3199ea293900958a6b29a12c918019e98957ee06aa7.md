Now, let's try to fit a line to these data points. Let's go few slides back…

- PCA projects the data onto this line
- PCA measures the distances from the data to the **line** and tries to find the line which **minimizes** those distances
- This the same as to find the **line** that **maximizes** the distances from the projected points to the origin (equivalent statement)
