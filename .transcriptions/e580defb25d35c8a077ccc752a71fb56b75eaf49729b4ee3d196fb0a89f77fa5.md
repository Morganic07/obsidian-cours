Les opérations binaires évaluent au début le premier opérande, et ensuite le deuxième opérande.

C'est important quand on a des effets secondaires (side effects)

```java
int a = 0;
int x = a + ++a;
System.out.println(" x= " + x);
```

```java
int a = 0;
int x = ++a + a;
System.out.println(“x= " + x);
```

Figure : Deux blocs de code côte à côte, chacun surmonté d'une flèche vers le bas. La flèche sous le bloc de gauche mène au résultat « 1 », celle sous le bloc de droite au résultat « 2 ».

Vérifié sur l'image : le deuxième bloc ouvre la chaîne par un guillemet typographique (`“x= "`), le premier par un guillemet droit (`" x= "`) ; recopiés tels qu'ils apparaissent.
