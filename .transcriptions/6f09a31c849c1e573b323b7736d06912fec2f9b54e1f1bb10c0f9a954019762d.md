Power series enable to approximate some usual constants. We start with the Maclaurin series

$$\forall x \in ]-1,1[,\ \arctan x = \sum_{n=0}^{+\infty} (-1)^n \frac{x^{2n+1}}{2n+1}$$

When $x = 1$, we have an alternating series, which is convergent. This gives

$$\pi = 4\sum_{n=0}^{+\infty} (-1)^n \frac{1}{2n+1}$$

We want to approximate $\pi$. Since we have an alternating series, we know that

$$|R_n(1)| \leq |a_{n+1}| = \frac{1}{2n+3}$$

For example, if we want to have an accuracy of $10^{-2}$, we need to take $n \geq 49$.
