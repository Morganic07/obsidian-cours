| Actions sur la file | Méthodes de la classe *File* |
|---|---|
| Enfiler un nouvel élément | `enfiler(élément)` |
| Défiler | `defiler()` |
| La file est-elle vide ? | `estVide()` |
| Afficher le nombre d’éléments présents dans la file | `longeur()` |
