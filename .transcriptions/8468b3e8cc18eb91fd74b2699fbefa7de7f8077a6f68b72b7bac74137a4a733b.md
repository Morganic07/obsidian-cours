Capture de terminal : aide de la commande `cp`.

```
momo@penguin:~$ cp --help
Usage: cp [OPTION]... [-T] SOURCE DEST
  or:  cp [OPTION]... SOURCE... DIRECTORY
  or:  cp [OPTION]... -t DIRECTORY SOURCE...
Copy SOURCE to DEST, or multiple SOURCE(s) to DIRECTORY.
```

Principales options affichées, résumées (voir l'image pour le texte complet) :

- `-a`, `--archive` : équivaut à `-dR --preserve=all`
- `-f`, `--force` : si le fichier de destination ne peut pas être ouvert, le supprimer et réessayer
- `-i`, `--interactive` : demander avant d'écraser
- `-l`, `--link` : créer des liens physiques au lieu de copier
- `-L`, `--dereference` : toujours suivre les liens symboliques de SOURCE
- `-n`, `--no-clobber` : ne pas écraser un fichier existant
- `-P`, `--no-dereference` : ne jamais suivre les liens symboliques de SOURCE
- `-p` : équivaut à `--preserve=mode,ownership,timestamps`
- `-R`, `-r`, `--recursive` : copier les dossiers récursivement
- `-s`, `--symbolic-link` : créer des liens symboliques au lieu de copier
- `-t`, `--target-directory=DIRECTORY` : copier tous les arguments SOURCE dans DIRECTORY
- `-T`, `--no-target-directory` : traiter DEST comme un fichier normal
- `-u`, `--update` : copier seulement si la source est plus récente ou si la destination manque
- `-v`, `--verbose` : expliquer ce qui est fait
- `-x`, `--one-file-system` : rester sur ce système de fichiers
- `--help`, `--version` : afficher l'aide ou la version
