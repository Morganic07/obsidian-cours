Schéma des quatre sous-espaces fondamentaux :

Dans $\mathbb{R}^n$ :

- **Row space** : $C(A^T)$ = all $A^T\mathbf{y}$, dim = rank $r$
- **Nullspace** : $N(A)$ : $A\mathbf{x} = 0$, dim = $n - r$

Dans $\mathbb{R}^m$ :

- **Column space** : $C(A)$ = all $A\mathbf{x}$, dim = rank $r$
- **Left Nullspace** : $N(A^T)$ : $A^T\mathbf{y} = 0$, dim = $m - r$
