# The case n=2

**Corollary**
For any two rvs $X_1$ and $X_2$, and any constants $a_1$, $a_2$, $b$,

$$E(a_1X_1 + a_2X_2 + b) = a_1E(X_1) + a_2E(X_2) + b$$

and

$$\mathrm{Var}(a_1X_1 + a_2X_2 + b) = a_1^2\mathrm{Var}(X_1) + a_2^2\mathrm{Var}(X_2) + 2a_1a_2\mathrm{Cov}(X_1, X_2)$$

In particular, $E(X_1 + X_2) = E(X_1) + E(X_2)$ and, if $X_1$ and $X_2$ are independent, $\mathrm{Var}(X_1 + X_2) = \mathrm{Var}(X_1) + \mathrm{Var}(X_2)$.$^1$ Also, $E(X_1 - X_2) = E(X_1) - E(X_2)$ and, if $X_1$ and $X_2$ are independent,

$$\mathrm{Var}(X_1 - X_2) = \mathrm{Var}(X_1) + \mathrm{Var}(X_2).$$

$^1$ This property of independent rvs can also be written as $\mathrm{SD}(X_1)^2 + \mathrm{SD}(X_2)^2 = [\mathrm{SD}(X_1 + X_2)]^2$. In part because the formula has the format $a^2 + b^2 = c^2$, statisticians sometimes call this property the *Pythagorean Theorem*.
