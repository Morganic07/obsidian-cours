**1.2 Redirection**

Redirect command output or input to/from files or other commands (e.g. **>**, **>>**, **<**, **|**).

- **>** — Redirects command output to a file, creating or overwriting the file.

`echo "Hello" > file.txt   # Writes "Hello" to file.txt, overwriting it`

- **>>** — Redirects output to a file, appending to the file.

`echo "World" >> file.txt  # Appends "World" to file.txt`

- **<** — Redirects input from a file.

`wc -l < file.txt          # Counts lines in file.txt`

- **|** — Pipes output one command as input to another.

`ls | grep "file"          # Lists files and filters output for "file"`
