- Méthode en 3 étapes :
  - 1) La définition du dictionnaire de données : lister les données non décomposables, leur type et leurs caractéristiques : obligatoire / optionnel ; valeur par défaut ; contraintes particulières.
  - 2) Le schéma Entités / Associations : schéma E/A (*E/R Entity / Relationship diagram*) : MCD = Modèle Conceptuel de Données.
  - 3) Le schéma relationnel : MLD = Modèle Logique de Données.
