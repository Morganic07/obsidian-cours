3. Le taux d'erreur global ($Er$)

Plutôt que de se fier à une seule évaluation potentiellement chanceuse, on calcule la moyenne des erreurs commises sur les trois tests : PNG

$$Er = \frac{Er_A + Er_B + Er_C}{3} = \frac{5 + 9 + 7}{3} = 7\,\%$$
