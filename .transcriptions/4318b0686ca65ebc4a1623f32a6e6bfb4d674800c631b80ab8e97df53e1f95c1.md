Figure : Schéma du cycle de vie d'un processus avec `fork()`. Le parent appelle `pid = fork()`. Le chemin « parent (pid > 0) » mène directement à `wait()`. Le chemin « child (pid = 0) » passe par `exec()`, puis `exit()`, puis remonte vers `wait()`. Après `wait()`, le parent reprend (« parent resumes »).
