| Type | Description | Examples |
|---|---|---|
| IGP | Used inside an autonomous system (AS) | RIP, EIGRP, OSPF |
| EGP | Used between autonomous systems | BGP |

☐ **IGP (Interior Gateway Protocol)**

- Optimized for speed and convergence **within** one organization.
- Handle internal routing efficiently.

☐ **EGP (Exterior Gateway Protocol)**

- Used to connect different organizations' networks.
- Focuses on policy, scalability, and path selection.

**Analogy:**

**IGP** is like routing within a city – It determines the best path between streets inside the city.

**EGP** is like routing between cities – It determines the best path between cities.
