# Hiererachical clustering Algorithm

- Input : N examples
- N clusters $G_i \leftarrow x_i$
- Label $G_i$.
- For d=1 to N-1
  - *Chose* $G_i, G_j$ labaled.
  - Merge them : $G_d \leftarrow G_i \cup G_j$.
  - Unlabel $G_i, G_j$.
  - Label $G_d$.
