$S = \{\omega_1, \omega_2, \dots, \omega_n, \dots\}$

To each sample point $\omega_i$ we assign a «weight » $p_i$ that satisfies two conditions:

i) $\forall i = 1,2,\dots:\quad p_i \geq 0$

ii) $\sum_i p_i = 1$

Figure : Une bulle bleue pointe vers la condition i) avec le texte « The weights $p_i$ do not need to be equal! ».

We define

$\forall i = 1,2,\dots : P(\omega_i) = p_i$

and for any subset $A \subset S$ we define

$P(A) = \sum_{\omega_i \in A} P(\omega_i) = \sum_{\omega_i \in A} p_i$

We can also write $P(A) = \sum_{\omega \in A} P(\omega)$
