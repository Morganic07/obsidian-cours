Figure : Schéma d'une interface sans contact reliée à une puce à contacts. L'interface contient cinq blocs : « Redresseur et limiteurs de tension », « Power-On-Reset », « Récupération d'horloge », « Modulateur » et « Démodulateur ». Une antenne (bobine L en parallèle avec un condensateur C) est branchée à gauche. Les blocs sont reliés aux contacts de la puce : le redresseur à C1 (VCC) et à C5 (GND), le Power-On-Reset à C2 (RST), la récupération d'horloge à C3 (CLK), et le modulateur et le démodulateur ensemble à C7 (I/O).

**Interface sans contact**

- Redresseur et limiteurs de tension
- Power-On-Reset
- Récupération d'horloge
- Modulateur
- Démodulateur

Antenne : L, C

Contacts de la puce :

| | | |
|---|---|---|
| C1 VCC | | GND C5 |
| C2 RST | | nc C6 |
| C3 CLK | | I/O C7 |
| C4 nc | | nc C8 |
