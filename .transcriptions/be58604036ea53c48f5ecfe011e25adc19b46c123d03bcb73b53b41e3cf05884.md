**Définition**

Soit $E_1, E_2, ..., E_n$ $n$ ensembles. On appelle **produit cartésien** des ensembles $E_i$, noté $E_1 \times E_2 \times ... \times En$ l'ensemble des n-uplets $(x_1, x_2, ..., x_n)$ où $x_i \in E_i$ pour $i = 1, ..., n$.
Si $E_1 = E_2 = ... = E_n = E$, le produit cartésien se note $E^n$.
