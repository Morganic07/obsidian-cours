Write a C program for Unix-like systems that creates a parent and a child process using the `fork()` system call. Before running the program, ensure a file named `time.txt` is created at the location `/home/user/data/time.txt`.

- The parent process should continuously append the current system time to the `time.txt` file every 5 seconds.
- The child process should create a backup of the `time.txt` file by copying it to `/home/user/backup/time.txt` every 10 seconds. The backup process should overwrite the previous version of the file at the backup location.

Once implemented, run the program in the background and ensure both processes operate independently. When finished terminate the background job.
