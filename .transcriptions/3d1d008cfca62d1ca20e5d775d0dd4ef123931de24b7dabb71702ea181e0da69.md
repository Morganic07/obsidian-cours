| Command | Purpose |
|---|---|
| `show ip protocols` | Displays routing protocol settings (RIP timers, networks, neighbors, default-originate, version, etc.). |
| `Show ip rip database` | Shows the RIP routing database and learned routes. |
| `show ip route rip` | Displays only the routes learned via RIP. |
| `show ip route` | Displays the full IPv4 routing table. |
| `no router rip` | Delete entire RIP configurations from the router. |
