$A^{-1} = \frac{1}{\det A}(\text{adj } A) \Leftrightarrow A^{-1}A = \frac{1}{\det A}(\text{adj } A)A \Leftrightarrow I = \frac{1}{\det A}(\text{adj } A)A \Leftrightarrow \det A = (\text{adj } A)A$

À vérifier : la dernière égalité est recopiée telle qu'elle figure sur l'image, mais le membre de gauche devrait être une matrice : on attendrait $(\det A)\,I = (\text{adj } A)A$.
