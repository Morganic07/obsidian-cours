| Fonction | Primitive |
|---|---|
| $e^x$ | $e^x$ |
| $\ln x$ | $x \ln x - x$ |
| $\dfrac{1}{x}$ | $\ln\lvert x\rvert$ |
| $x^{\alpha}$ $(\alpha \neq -1)$ | $\dfrac{x^{\alpha+1}}{\alpha+1}$ |

| Fonction | Primitive |
|---|---|
| $\sin x$ | $-\cos x$ |
| $\cos x$ | $\sin x$ |
| $\tan x$ | $-\ln\lvert\cos x\rvert$ |
