Figure : Diagramme de files d'attente de l'ordonnancement des processus. Les processus entrent dans la « ready queue », puis passent au « CPU ». Depuis le CPU, ils peuvent :
- faire une « I/O request », aller dans l'« I/O wait queue », passer par « I/O », puis revenir dans la « ready queue » ;
- subir l'expiration du quantum (« time slice expired ») et retourner directement dans la « ready queue » ;
- créer un processus fils (« create child process »), attendre dans la « child termination wait queue », puis, quand « child terminates », revenir dans la « ready queue » ;
- attendre une interruption (« wait for an interrupt »), aller dans l'« interrupt wait queue », puis, quand « interrupt occurs », revenir dans la « ready queue ».

Les processus peuvent aussi quitter le système depuis le CPU, par la flèche de sortie à droite.
