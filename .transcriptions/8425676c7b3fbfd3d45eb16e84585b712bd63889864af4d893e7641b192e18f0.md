1. In the definition of uniform convergence, the value of $N$ depends only on $\epsilon$ and is the same for all $x \in X$, which is not the case for pointwise convergence.
2. Uniform convergence implies pointwise convergence but the converse is not true as we will see below.
3. For example, if $N = 100$, uniform convergence means that the functions $f_{100}, f_{101}, f_{102}, \ldots$ are contained on the tube $[f - \epsilon, f + \epsilon]$.
