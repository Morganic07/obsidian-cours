1. Le "Poids" des variables (Weighting)

Chaque Composante Principale (PC) est une nouvelle variable créée à partir d'une combinaison de tes variables d'origine ($a1, a2, \ldots$). Le loading est le chiffre qui indique **quelle quantité** de chaque variable on a mis dans le mélange.

- **Exemple mathématique :** Si $PC1 = (0,9 \times a1) + (0,1 \times a2)$, alors $0,9$ et $0,1$ sont les loadings.
- **Analyse :** Ici, $a1$ est le "moteur" du PC1. $a2$ n'est qu'un ingrédient mineur.

2. La corrélation avec l'axe

Le loading est en réalité le coefficient de corrélation entre la variable d'origine et la composante principale.

- **Loading proche de +1 :** La variable et le PC sont fortement liés. Si l'un monte, l'autre monte.
- **Loading proche de -1 :** Ils sont inversement liés. Si la variable monte, le score du PC descend.
- **Loading proche de 0 :** La variable n'a aucune influence sur ce PC. Elle "parle" d'autre chose.
