On peut procéder par substitution, pour calculer la solution générale de cette équation :

$T(n) = b + T(n-1)$

$\quad = b + [b + T(n-2)] = 2b + T(n-2)$

$\quad = ib + T(n-i)$

$\quad = ib + [b + T(n-i+1)]$

$\quad = (n-1)b + [T(n-n+1)] = nb - b + T(1) = nb - b + c$

$T(n) = nb - b + c \rightarrow O(n)$
