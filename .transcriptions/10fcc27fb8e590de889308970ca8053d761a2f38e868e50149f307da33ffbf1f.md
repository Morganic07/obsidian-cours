# Définition

- Une liste chaînée simple est une structure dynamique qui est composée d'un ensemble d'éléments (dits **cellules** ou **nœuds** aussi) tel que chacun :
  - ✓ Est rangé en mémoire à une certaine adresse,
  - ✓ Contient une donnée (*valeur* *de type quelconque*),
  - ✓ Contient un pointeur, souvent nommé *suivant*, l'adresse de l'élément suivant dans la liste.
