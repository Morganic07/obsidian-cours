| Opérateur | Signification |
|---|---|
| `==` | c'est le test d'équivalence |
| `!=` | différent (non équivalence) |
| `>` | supérieur |
| `>=` | supérieur ou égal |
| `<` | inférieur |
| `<=` | inférieur ou égal |
| `&&` | ET logique |
| `\|\|` | OU logique |
| `!` | NOT logique |
| `^` | XOR logique |

À vérifier : le haut de l'image est coupé. On devine une ligne de texte, probablement « souvent il s'agit des opérations logiques : », mais elle n'est pas lisible.
