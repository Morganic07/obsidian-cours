Figure : Schéma de la disposition mémoire d'un processus, de la mémoire haute (« high memory ») à la mémoire basse (« low memory »). Les blocs, de haut en bas, sont : argc, agrv ; stack ; une zone en pointillés avec deux flèches (l'une vers le bas, l'autre vers le haut) ; heap ; uninitialized data ; initialized data ; text. Des flèches relient le code C à droite à ces zones : `argc, argv` vers « argc, agrv », `int *values; int i;` vers « stack », `int x;` vers « uninitialized data », `int y = 15;` vers « initialized data », et le `malloc` vers « heap ».

```c
#include <stdio.h>
#include <stdlib.h>

int x;
int y = 15;

int main(int argc, char *argv[])
{
    int *values;
    int i;

    values = (int *)malloc(sizeof(int)*5);

    for(i = 0; i < 5; i++)
        values[i] = i;

    return 0;
}
```

À vérifier : le bloc du haut est écrit « argc, agrv » sur l'image, alors que le code utilise `argv`.
