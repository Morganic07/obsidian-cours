Path and Circuit

- **Path**: A *path* in a graph is a sequence of vertices $v_1, v_2, \ldots, v_k$ such that for every $i$ (where $1 \leq i < k$), there is an arc connecting $v_i$ and $v_{i+1}$. An elementary path does not repeat vertices. A simple path does not repeat arcs.

- **Circuit**: A *circuit* in a graph is a closed path that starts and ends at the same vertex.
