- Syntaxe :

```
for (initialisation; condition; itération) {
    … séquence d'instructions…
}
```

- Trois parties:
  - *Initialisation* pour définir la variable ou les variables de contrôle de la boucle
  - *Condition* pour définir la condition pour exécuter la séquence d'instructions
  - *Itération* pour changer les valeurs de contrôle des variables pour chaque itération

- Cette boucle est utilisée quand le nombre d'itération est connu.
