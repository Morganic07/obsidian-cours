We have

$f(x) = \sin x \qquad f(0) = 0$

$f'(x) = \cos x \qquad f'(0) = 1$

$f''(x) = -\sin x \qquad f''(0) = 0$

$f^{(3)}(x) = -\cos x \qquad f^{(3)}(0) = -1$

$f^{(4)}(x) = \sin x \qquad f^{(4)}(0) = 0$

More generally, we have

$f^{(4n)}(x) = \sin x \qquad f^{(4n)}(0) = 0$

$f^{(4n+1)}(x) = \cos x \qquad f^{(4n+1)}(0) = 1$

$f^{(4n+2)}(x) = -\sin x \qquad f^{(4n+2)}(0) = 0$

$f^{(4n+3)}(x) = -\cos x \qquad f^{(4n+3)}(0) = -1$
