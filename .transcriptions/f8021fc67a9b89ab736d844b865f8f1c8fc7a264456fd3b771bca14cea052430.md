Figure : Repère $(x, y)$ dont le demi-plan gauche $x<0$ est hachuré par des droites obliques. Il est annoté « $\theta \in\ ]\frac{\pi}{2}; \frac{3\pi}{2}[$ » et « $x < 0$ ».

Alors le $\mathcal{C}^1$-difféomorphisme est défini par

$$\phi \ : \ \mathbb{R}_+^* \times ]\tfrac{\pi}{2}; \tfrac{3\pi}{2}[ \ \to \ \mathbb{R}_-^* \times \mathbb{R}$$

$$(\rho, \theta) \ \mapsto \ (x, y) = (\rho\cos(\theta), \rho\sin(\theta))$$

$$\phi^{-1} \ : \ \mathbb{R}_-^* \times \mathbb{R} \ \to \ \mathbb{R}_+^* \times ]\tfrac{\pi}{2}; \tfrac{3\pi}{2}[$$

$$(x, y) \ \mapsto \ (\rho, \theta) = \left(\sqrt{x^2+y^2}, \pi + Arctan\left(\tfrac{y}{x}\right)\right)$$
