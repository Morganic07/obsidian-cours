Definition: Two events $A, B$ are independent if $P(A|B) = P(A)$ and they are dependent otherwise.

Note that if $A$ and $B$ are independent, then also $P(B|A) = P(B)$ holds.

Consequence:

Two events $A, B$ are independent if and only if $P(A \cap B) = P(A)P(B)$.

If A and B are independent events, then

i) $A^c, B$ are independent

ii) $A, B^c$ are independent

iii) $A^c, B^c$ are independent
