Avec les valeurs des indices

```java
valeurs[2] = 4;
matrice[0][0] = 1;
```

les indices prennent des valeurs de 0 à taille – 1 de chaque dimension

Avec l'énumération de valeurs dans la définition :

```java
int valeurs[] = { 5, 2, 4, 8, 9};
int matrice [ ][ ] = { {1, 2, 3}, {4, 5, 6}, {7, 8, 9} };
```
