We define the class of functions for which we will compute Fourier series: piece-wise continuous functions.

> **Definition**
>
> A function is called piece-wise continuous function on an interval if the interval can be subdivided into a finite number if intervals in each of which the function is continuous and has finite right- and left-hand limits. Such a function has only a finite number of discontinuities.

À vérifier : « finite number if intervals » est recopié tel quel. Le texte source dit « if » là où l'on attendrait « of ».
