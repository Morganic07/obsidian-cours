Soit

$$P(n) = \frac{n(n+1)}{2}$$

<span style="color:red">Initialisation</span> : Vérifions que $P(1)$ est vraie ;

$$P(1) = 1 = \frac{1 \times 2}{2}$$

Donc $P(1)$ est vraie.

<span style="color:red">Hérédité</span> : Soit un entier $n \geq 1$. Supposons que $P(n)$ est vraie et montrons que $P(n+1)$ est vraie ;

$$1+2+\ldots+n+n+1 = \frac{n(n+1)}{2} + (n+1) = (n+1)\left[\frac{n}{2}+1\right] = \frac{(n+1)(n+2)}{2}$$

Donc $P(n+1)$ est vraie ;

<span style="color:red">Conclusion</span> : $P(1)$ est vraie et $P(n)$ est héréditaire à partir du rang 1, donc par récurrence, $P(n)$ est vraie pour tout $n \geq 1$.
