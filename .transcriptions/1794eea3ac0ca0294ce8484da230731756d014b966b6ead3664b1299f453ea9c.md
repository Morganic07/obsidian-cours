# Linear combinations of arbitrary rvs

**THEOREM**

Let the rvs $X_1, X_2, \ldots, X_n$ have mean values $\mu_1, \ldots, \mu_n$ and standard deviations $\sigma_1, \ldots, \sigma_n$, respectively.

1. Whether or not the $X_i$s are independent,

$$E(a_1X_1 + \cdots + a_nX_n + b) = a_1E(X_1) + \cdots + a_nE(X_n) + b$$
$$= a_1\mu_1 + \cdots + a_n\mu_n + b$$

and

$$\mathrm{Var}(a_1X_1 + \cdots + a_nX_n + b) = \sum_{i=1}^{n}\sum_{j=1}^{n} a_i a_j \mathrm{Cov}(X_i, X_j)$$
$$= \sum_{i=1}^{n} a_i^2\sigma_i^2 + 2\sum_{i<j}\sum a_i a_j \mathrm{Cov}(X_i, X_j)$$
