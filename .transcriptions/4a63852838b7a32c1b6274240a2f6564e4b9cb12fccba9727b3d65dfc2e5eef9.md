- Define the *inside* interface(s) connected to the internal network

```
R1(config)#interface gigabitEthernet 0/1
R1(config-if)#ip nat inside
```

- Define the *outside* interface(s) connected to the external network

```
R1(config)#interface gigabitEthernet 0/0
R1(config)#ip nat outside
```

- Define the traffic that should be translated

```
R1(config)#access-list 1 permit 192.168.0.0 0.0.0.255
```

- Configure PAT by mapping the ACL to the interface and enabling **overlead**

```
R1(config)# ip nat inside source list 1 interface g0/0 overlead
```

À vérifier : « overlead » est écrit ainsi dans l'image (la commande Cisco correcte est « overload »). J'ai recopié tel quel.
