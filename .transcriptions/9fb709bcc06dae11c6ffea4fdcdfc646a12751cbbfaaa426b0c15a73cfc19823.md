**Exemple** de **déclaration** de fonction :

Figure : Déclaration de fonction `float moyenne (int a, int b) ;` annotée par des flèches. Le type de retour est `float`, le nom de la fonction est `moyenne` et les paramètres sont entre parenthèses. Chaque paramètre est décomposé en son type (`int`) et son nom (`a`, `b`).

- *type de retour de la fonction* → `float`
- *nom de la fonction* → `moyenne`
- *parametres* → `(int a, int b)`
- *type du param. 1* → `int`
- *nom du param. 1* → `a`
- *type du param. 2* → `int`
- *nom du param. 2* → `b`

```
float moyenne (int a, int b) ;
```

Cette déclaration signifie que dorénavant le compilateur "sait" qu'il existe un symbole appelé `moyenne`, qui est une fonction à deux paramètres entiers et renvoyant un résultat réel.

Une fois déclarée, la fonction peut être appelée n'importe où dans le programme, le compilateur vérifiera juste à l'endroit de l'appel que le nombre et le type des paramètres, ainsi que la valeur de retour, sont en cohérence avec le profil déclaré.
