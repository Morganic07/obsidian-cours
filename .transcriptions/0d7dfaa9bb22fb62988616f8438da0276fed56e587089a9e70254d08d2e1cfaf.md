```bash
#!/bin/bash

SOURCE="/home/momo/backup/memory.txt"
DESTINATION="/home/momo/data/"
while true; do
 cp "$SOURCE" "$DESTINATION"
 echo "$Backup Successful!"
 sleep 20
done
```

À vérifier : dans la commande `echo`, le texte apparaît comme `"$Backup Successful!"`, avec un `$` devant « Backup ». C'est peut-être une faute de frappe dans l'original.
