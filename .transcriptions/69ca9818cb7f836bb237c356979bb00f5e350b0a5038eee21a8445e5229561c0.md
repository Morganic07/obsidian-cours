**1.4 Grouping and Quoting:**

Group commands or preserve literal text values (e.g. `( )`, `{ }`, `' '`, `" "`)

- **( )** — Group commands to run in a subshell.

```
(cd folder && ls)        # Changes to folder, lists contents, then returns
```

- **{ }** — Group commands in the current shell.

```
{ mkdir new_folder; cd new_folder; touch newfile.txt; }
```

- **' '** (Single Quotes) — Preserves the literal value of each character inside the quotes.

```
echo 'path $PWD'      # Outputs "Hello $PWD" (without expanding $PWD)
echo $PWD             # Outputs the path to the working directory. Note the
                      # output difference in the two commands.
echo ‘Hello $USER’    # Outputs “Hello $USER” (without expanding $USER)
echo $USER            # outputs “Hello <username>”
```

- **" "** (Double Quotes) — Preserves most characters but allows variable expansion.

```
echo "Hello $USER"    # Outputs "Hello <username>"
echo “Path $PWD”      # Outputs “Path </path to the working directory>
```

À vérifier : les commentaires de `echo 'path $PWD'` et de `echo $USER` ne correspondent pas aux commandes (« Hello » au lieu de « path », et « Hello » en trop). Le dernier commentaire n'a pas de guillemet fermant.
