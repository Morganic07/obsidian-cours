Figure : Hiérarchie des périphériques de stockage, présentée comme une pyramide de blocs allant des registres en haut jusqu'aux bandes magnétiques en bas. À gauche, une flèche « storage capacity » va de *smaller* (en haut) à *larger* (en bas). À droite, une flèche « access time » va de *faster* (en haut) à *slower* (en bas). Des flèches à double sens relient chaque niveau au suivant.

Niveaux, de haut en bas :
- registers
- cache
- main memory
- nonvolatile memory
- hard-disk drives
- optical disk
- magnetic tapes

Annotations :
- Une ligne pointillée sépare *volatile storage* (registers, cache, main memory) de *nonvolatile storage* (nonvolatile memory et les niveaux inférieurs).
- À droite, des accolades regroupent les niveaux :
  - **primary storage** : registers, cache, main memory
  - **secondary storage** : nonvolatile memory, hard-disk drives
  - **tertiary storage** : optical disk, magnetic tapes

Texte des axes : storage capacity, smaller, larger, access time, faster, slower.
