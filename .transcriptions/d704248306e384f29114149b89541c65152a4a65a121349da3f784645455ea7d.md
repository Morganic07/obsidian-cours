Algorithm 1

Let $G = (V, E)$ be a directed graph. For each vertex $v \in V$, we define two sets:

- The set of descendants of $v$: $D(v) = \{v' \in V \mid v\ \sigma\ v'$ *and* $\sigma$ *is a path which allows to reach* $v'$ *starting from* $v\}$.
- The set of ancestors of $v$: $A(v) = \{v' \in V \mid v'\ \sigma\ v\}$
- Principle: Starting from a vertex $v$, we compute the *SCC* to which $v$ belongs.
  - We compute the set of descendants of $v$ (denoted $D(v)$).
  - We compute the set of ancestors of $v$ (denoted $A(v)$).
  - The *SCC* containing $v$ is $\{v\} \cup (A(v) \cap D(v))$.
