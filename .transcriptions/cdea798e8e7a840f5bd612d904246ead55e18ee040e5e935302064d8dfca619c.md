# Le nom d'un tableau est l'adresse de la première case du tableau

```
for(i=0;i<6;i++) printf(« l'adresse de effectifs[%d] est %p \n»,i, &effectifs[i]);
```

| | | |
|---|---|---|

| 0x16fdab76 | 0 | |
| 0x16fdab7a | 1 | 38 |
| 0x16fdab7e | 2 | |
| 0x16fdab82 | 3 | |
| 0x16fdab86 | 4 | |

```
l'adresse de effectifs[0] est 0x16d383610
l'adresse de effectifs[1] est 0x16d383614
l'adresse de effectifs[2] est 0x16d383618
l'adresse de effectifs[3] est 0x16d38361c

pierre@Ijen pointeurs %
```

À vérifier : les adresses du tableau (0x16fdab…) ne correspondent pas à celles de la sortie du terminal (0x16d3836…). Dans le tableau, la première ligne (0x16fdab72) n'a pas d'indice, et 0x16fdab72 n'est pas aligné sur 4 octets comme les autres adresses.
