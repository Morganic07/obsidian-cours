Definition

Let $I$ be a symmetrical interval about the origin and $f$ be a function defined on $I$. We say that $f$ is an odd function if $\forall x \in I,\ f(-x) = -f(x)$.

Proposition

Let $f$ be a $2\pi$-periodic, piece-wise continuous and odd function defined on $\mathbb{R}$. Then we have

$$\forall n \geq 0,\ a_n = 0,\ \text{and}\ \forall n \geq 1,\ b_n = \frac{2}{\pi}\int_0^{\pi} f(x)\sin nx\,dx$$

Therefore

$$FS(f)(x) = \sum_{n=1}^{+\infty} b_n \sin nx$$
