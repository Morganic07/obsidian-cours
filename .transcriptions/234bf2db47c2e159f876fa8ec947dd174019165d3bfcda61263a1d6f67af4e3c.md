*Conseil : revoir les formules de trigo !!!*

- $\cos(x+y) = \cos x \cos y - \sin x \sin y$
- $\cos(x-y) = \cos x \cos y + \sin x \sin y$
- $\sin(x+y) = \sin x \cos y + \cos x \sin y$
- $\sin(x-y) = \sin x \cos y - \cos x \sin y$

- $\cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - \sin^2 x$
- $\sin 2x = 2\sin x \cos x$

À vérifier : la dernière égalité de $\cos 2x$ est écrite « $1 - \sin^2 x$ » dans l'image, mais la formule usuelle est $1 - 2\sin^2 x$.
