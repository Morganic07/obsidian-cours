**Definition**

An *oriented graph* is a directed graph obtained by assigning a direction to each edge of an undirected graph. Formally, an oriented graph is a pair $G = (V, A)$, where:

- $V$ is a set of vertices,
- $A \subseteq V \times V$ is a set of directed arcs.
