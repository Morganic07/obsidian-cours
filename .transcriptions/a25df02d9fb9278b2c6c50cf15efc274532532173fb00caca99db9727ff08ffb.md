Une constante est une variable de valeur fixe qui doit être déclarée et ne peut pas être modifiée pendant la durée de vie du programme exécuté.

Mot clé 'Final'.

```java
public class Exemple {

   public static void main(String[] args)
   {
      final int MOIS = 12;  // écrire les constantes en majuscules
      System.out.print(MOIS);
      MOIS = 3 ;
   }
}
```

Figure : une flèche rouge pointe de la ligne `MOIS = 3 ;` vers l'annotation rouge « Erreur de compilation ».

À vérifier : le mot clé est écrit « Final » avec une majuscule dans le texte, alors que le code utilise `final` en minuscule.
